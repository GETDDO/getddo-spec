# 요구사항

GETDDO 프로젝트가 무엇을 제공하고 이번 구현에서 어디까지 다룰지 관리합니다.

## 관리 범위

- 프로젝트 주제와 목표
- 전체 전제 조건
- 기능 요구사항
- 구현, 보류 및 제외 범위
- 아직 확정되지 않은 정책

## 예정 문서

| 문서 | 내용 |
| --- | --- |

| scope.md | 구현, 보류 및 제외 범위 |
