# 요구사항

GETDDO 프로젝트가 무엇을 제공하고 이번 구현에서 어디까지 다룰지 관리합니다.

## 프로젝트 주제와 목표

GETDDO는 커머스 서비스의 경품 이벤트를 소재로 한 이벤트 응모 및 추첨 플랫폼입니다. 응모권 지급·사용 이력과 보유 응모권 수의 일치, 중복 요청 방지, 추첨 인원과 결과의 정합성을 다룹니다.

백엔드는 삭제 없는 이력과 실행 중복 방지, 추첨 결과의 정합성을 설계합니다. 프론트엔드는 이벤트 참여 화면부터 운영자용 백오피스까지 사용자 흐름을 구현합니다.

## 전체 전제와 문서 기준

- 가상 회원과 더미 데이터로 참여·추첨·검증을 시연한다.
- 실제 외부 알림 발송은 모의 처리한다.
- 공개하는 당첨 결과의 개인정보는 마스킹한다.
- 이벤트 구성, 보상 규칙, 추첨 방식 및 화면 기획은 아래 기능 요구사항과 도메인 규칙의 확정 내용을 따른다.
- 초기 프로젝트 안내에서 선택 사항으로 제시한 실시간 응모 현황, 어뷰징 탐지 및 가중치 추첨의 현재 범위는 기능 요구사항을 따른다.

이벤트 응모의 중복 방지·응모권 이력 및 보유 응모권 정합성, 추첨 후보·조건 보존, 백오피스 기능은 [기능 요구사항](functional-requirements.md)과 [도메인 규칙](../02-domain/README.md)에서 관리한다. 기존 백엔드의 프로젝트 소개를 이 문서로 통합했으며, 초기 안내보다 구체적인 확정 요구사항을 우선한다.

## 관리 범위

- 프로젝트 주제와 목표
- 전체 전제 조건
- 기능 요구사항
- 구현, 보류 및 제외 범위
- 아직 확정되지 않은 정책
