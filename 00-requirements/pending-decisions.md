# 미결정 사항과 담당자 후속 작업

사용자의 순차 답변을 일괄 반영했다. 확정 정책은 요구사항·도메인 문서를 기준으로 하며, 아래에서 보류와 담당자 후속 작업을 구분한다. 담당자가 운영 수치를 수정하는 일을 정책 자체의 미결정으로 해석하지 않는다.

## 게임

- [담당자 확정 후 공유] 제공할 게임 종류·규칙은 게임 담당자가 결정한다. 타코야끼 만들기는 후보이며 확정 게임이 아니다.
- [담당자 설계 후 공유] 서버 판정 원칙을 유지하고 게임별 유효성 검증 방식을 설계한다. 담당: 윤태형.
- 보상 초기화 시간, 동일 플레이 재시도 및 관리자 검토 적용은 [게임 규칙](../02-domain/game.md)으로 확정했다.

## 응모와 어뷰징

- [확정 정책의 담당자 관리·수정] 사용자별 빈도·비정상 요청 반복 탐지, 출석·미션·게임 지급 단계 탐지 및 사용자별 요청 빈도 제한을 적용한다. 세부 조건·시간·횟수는 담당자가 관리·수정한다. 담당: 석종수, 게임별 검증 연계: 윤태형.
- 위 항목은 적용 여부가 미정인 기능이 아니다. 기준은 [응모·어뷰징 규칙](../02-domain/entry.md)을 따른다.

## 추첨과 결과 발표

- [예외 처리 세부 미확정] 마감 + 5분에 자동 최초 발표하는 정상 흐름은 확정했다. 시스템 장애·정합성 오류로 결과를 확정하지 못했을 때의 사용자 문구, 복구·재시도 및 취소 전환 기준은 별도 결정이 필요하다. 정상 흐름에 관리자 승인 대기를 다시 추가하지 않는다. 미검토 의심만으로 제외하지 않는 기존 기준은 유지한다.

- [담당자 결정] 공개 명단의 이름·전화번호·이메일에 적용할 구체적인 마스킹 규칙. 화면과 공개 API 모두 마스킹한다.
- [세부 처리 미확정] 추첨 자료의 운영상 보관은 마지막 결과 공개·취소 후 5년(추후 수정 가능)이다. 탈퇴 기능은 제외했다. 개인정보 파기 시 익명화·집계 보존 방식은 사용자가 선택하지 않았으므로 임의로 확정하지 않는다. 운영상 5년을 개인정보의 일괄 법정 보존 근거로 해석하지 않는다.

## 배너

- [담당자 추후 확정] 이미지 허용 형식·파일당 용량 제한. JPG·PNG·WebP 및 5MB 등 제안 수치는 채택하지 않았다.

## 원문에서 확인되지 않은 항목 — 보류

- [보류] 변경 이력에는 운영 및 시연 15절, 공통 추가 검토 16절, 비기능 요구사항이 언급돼 있지만 전달된 최종 본문에는 해당 절이 포함돼 있지 않다. 원문 확인 항목을 유지한다.
- 배너 이미지 기준은 원문 확인과 별개로 담당자가 확정한다.

## 사용자 문맥과 알림 API

- [담당자 후속 작업] 등록된 `X-User-ID` 및 선택 멤버십 확인의 공통 처리 위치와 알림 API 연결 방식. 사용자 전달에 따르면 이경주 담당자가 해결할 예정이며, 구체적인 연결 방식과 완료 여부는 아직 확인되지 않았다. 사용자·역할·멤버십 및 공통 사용자 처리는 이경주, 알림 소유권 검증·조회·읽음 처리는 전민규 담당 영역이다.
- [세부 계약 미확정] `INACTIVE` 사용자 처리와 테스트 사용자 목록·시드 제공 방식은 [공통 사용자 문맥](../05-api/common.md#시연용-사용자-헤더--사용자-요청을-반영한-권고안)의 후속 확인 항목이다. 이번 N01~N03 확정으로 임의로 결정하지 않는다.
- [확정 범위] [N01~N03 요청·응답·오류 계약](../05-api/notification.md#사용자-알림--n01n03-확정)은 2026-09-30 확정했다. 공통 API 전체와 관리자 알림 AN01~AN05는 이 확정 범위에 포함하지 않는다.
