# 구현 범위

## 포함

- 기본 출석과 매월 초기화되는 연속 출석.
- 관리자가 수동 등록하는 서비스 공통 퀴즈·설문. 사용자당 미션별 1회 달성·보상.

- 응모권 지급 전 서버 검증·차단 기록과 관리자 조회. 구체적인 적용 대상·판정 기준은 후속 확인한다.

- 관리자 사유에 따른 개별 당첨 취소·빈 자리 재추첨. 취소 대상이 아닌 당첨자·경품은 유지하며 어뷰징·자격 미달 확인을 필수로 요구하지 않는다. 당첨 취소·재추첨을 이유로 응모권을 반환하거나 회수하지 않는다.

## 제외

### 관리자 인증 승인

- 미션 인증 제출 및 관리자 수동 승인·반려 기능은 이번 버전에서 제외한다.
- 제출 목록, 일괄 승인·반려, 승인 대기·승인 완료·반려 필터는 구현하지 않는다.
- 기존 응모권 지급 현황·검색 기능은 백오피스에서 제공한다.
- 어뷰징 차단 내역의 관리자 조회는 별개 기능으로 제공한다. 지급 후 부정의 점수 무효화·판단 근거 연계는 후속 확인한다. 일반 관리자 당첨 취소는 어뷰징 사후 처리와 구분해 추첨 기능에서 제공한다.

### 그 밖의 제외 범위

- 공통 감사 로그 검색·목록·상세 API(AU01/AU02)와 전용 조회 화면은 제공하지 않는다. 내부 감사 기록은 유지하며, 개별 업무의 운영 내역 조회는 해당 계약을 따른다. 기준은 [감사 기록 명세](../05-api/audit.md)다.

- 사용자 탈퇴 기능은 제공하지 않는다. 보관 목적·기간에 따른 개인정보 파기와는 별개다.
- 관리자는 사용자 정보를 조회만 할 수 있으며 수정할 수 없다.
- 실제 문자·이메일·외부 푸시는 이번 버전에서 제외한다.
- 사용자의 응모 취소는 제공하지 않는다.
- 별도 이의 제기는 이번 버전에서 제외한다.
- 관리자의 응모권 수동 지급·회수 기능은 이번 버전에서 구현하지 않는다.
- 부정 획득이 확인된 응모권의 회수도 이번 버전의 구현 범위에서 제외한다. 이벤트 취소에 따른 반환은 유지하며 추첨 제외에 따른 반환은 제공하지 않는다.
- 사용자 요청에 의한 당첨 취소는 제공하지 않는다. 당첨 취소에 연결되지 않은 임의 재추첨이나 확정된 동일 실행의 재선정은 제공하지 않는다.
- 주간 랭킹·게임 랭킹 보상은 신규 확정 기능으로 추가하지 않는다.

- 관리자의 참여 허용·추첨 제외 결정과 그에 따른 제외 사유 안내·응모권 반환은 제공하지 않는다.

## 추후 추가 예정

- 전체 당첨자를 취소하고 처음부터 다시 추첨하는 기능은 추후 추가 예정이며 이번 구현·완료 범위에 포함하지 않는다. 후보·가중치·과거 당첨자 자격·공개 전환·중복 처리의 상세 정책은 아직 확정하지 않았다.

## 사용자 추첨 결과 조회 — 2026-10-14 범위 확인

- GD-140은 공개 명단·본인 결과 조회를 구현하며 상세 계약은 [추첨 API](../05-api/drawing.md#사용자-결과-조회)를 따른다.
- 발표 후 취소·재추첨을 이번 운영에서 사용하지 않는 전제로, 그 사이 사용자 임시 표시·본인 중간 상태는 이번 GD-140에서 구현하지 않는다. 기존 관리자 기능과 API의 폐지·발표 후 호출 금지는 이번 변경에 포함하지 않는다.
- 미등록 개인정보에 대한 별도 대체 표시·문구는 이번 마스킹 작업 범위에서 다루지 않는다.

## 최초 공개 방식 — 2026-10-14 변경

- 자동 최초 추첨은 유지하며 관리자 육안 검토 후 발표 요청 한 번으로 최종 확인 기록과 명시적 수동 최초 공개를 함께 처리한다. 별도 확인 버튼·사전 확인 요청은 요구하지 않는다.
- 스케줄러의 자동 최초 공개·공개 재호출과 발표까지 5분 카운트다운은 이번 구현에서 제외한다.
- 기존 관리자 조회·개별 당첨 취소·빈 자리 재추첨과 실제 공개 버전의 사용자 조회는 재사용한다. 응모자 후보 제외를 되살리지 않는다.
