# 사용자 문맥 오류와 내 정보 비활성 거절 명세 정렬

- 상태: 검토 대기
- 일자: 2026-10-16

## 목적

사용자 요청에 따라 공통 사용자 문맥 오류와 U01의 누락된 거절 조건을 현행 백엔드 구현에 맞추고 spec main에 반영한다.

## 수행 내용과 확인된 사실

- spec main `00f16aa`와 BE dev `88833ce`의 문서·오류 정의·사용자 문맥 처리·Service·기존 테스트를 정적으로 대조했다.
- 변경 전: 공통 오류 표에 옛 제안 이름이 남아 있고, U01에는 비활성 사용자 거절 조건이 없었다.
- 변경 후: [공통 계약](../05-api/common.md#오류)에 실제 응답 번호와 조건을 반영하고, [본인 정보 계약](../05-api/user.md#본인-정보)에 현행 거절 조건을 명시했다.
- 관리자 사용자 조회 계약과 감사 범위는 이번 작업에서 변경하지 않았다.

## 영향과 검증

- FE는 문서에 남아 있던 옛 제안 이름 대신 현재 서버의 응답 코드를 기준으로 오류를 처리할 수 있다.
- 서버 동작·응답 형식·데이터 모델은 변경하지 않는다. 다른 업무의 비활성 사용자 허용 정책과 U01의 나머지 초안 상태는 유지한다.
- 변경 문서의 상대 링크와 diff 공백 오류를 확인했다. 문서만 변경하므로 테스트·빌드는 실행하지 않았다.
- 기존 작업 사본의 미커밋 변경을 보존하기 위해 최신 원격 main의 별도 사본에서 작업했다.

## 다음 할 일과 미결정 사항

- FE의 기존 오류 분기가 실제 응답 번호를 사용하는지 연동 시 확인한다.
- 다른 업무의 비활성 사용자 상태 제한과 테스트 사용자 목록·시드 제공 방식은 기존 후속 확인 범위를 유지한다.
