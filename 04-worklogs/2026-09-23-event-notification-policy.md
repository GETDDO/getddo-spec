> 후속 변경: 시작 시각 앞당김은 [ADR-012](../03-decisions/012-event-registration-and-editing-rules.md)에서 금지했고, 이벤트 삭제 시 알림 전체 제거는 사용자 정정으로 철회했다. 아래는 당시 작업 기록이며, 검토 항목 1~3과 6의 후속 결정은 [최신 작업 기록](2026-09-23-event-registration-and-editing.md)을 따른다.

## 목적

이벤트 CRUD 설계 검토에 대한 사용자의 알림 정책 답변을 공용 명세에 반영한다.

## 한 일

- 이벤트·알림 규칙과 ADR-008의 기존 일정 변경 안내를 확인했다.
- 사용자가 답한 일정 앞당김의 추가 알림 제외와 이벤트 삭제 시 기존 알림 제거를 [알림 규칙](../02-domain/notification.md)에 반영했다.
- [이벤트 규칙](../02-domain/event.md)에 삭제 시 알림 처리 기준 링크를 추가했다.
- 변경 전후와 영향을 [ADR-011](../03-decisions/011-event-notification-changes-and-deletion.md)에 기록하고 ADR-008에 후속 결정 링크를 추가했다.

## 확인된 내용

- 정책 기준은 위 도메인 문서이며, 작업 기록은 별도의 기준 문서로 사용하지 않는다.
- 검토 항목 1~4(등록·노출 흐름, 경품 등수 구조, 중단·취소 상태의 수정·삭제, 월말 소진 지정 조건)는 사용자가 현 단계에서 크게 신경 쓰지 않아도 된다고 답했다. 새 제약이나 확정 정책을 추가하지 않았으며 필수 선행 결정으로 취급하지 않는다.
- 이벤트 삭제와 취소를 구분하고, 사이트 내 알림 외의 감사 로그·모의 발송 이력 삭제를 새로 지시하지 않는다.
