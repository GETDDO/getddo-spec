# 응모권 최대 5장 사용 상한 반영

- 상태: 완료 — 로컬 문서 반영
- 날짜: 2026-09-22
- 목적: 사용자의 최대 5장 상한 요청을 공용 명세에 반영한다.

## 수행 내용

- 기능 요구사항, 응모·추첨·응모권 도메인에 사용자당 이벤트별 누적 5장 제한을 반영했다.
- 추가 응모로 상한을 초과하지 못하도록 명시하고 프론트엔드 표시와 서버 검증 기준을 추가했다.
- 월말 소진용 이벤트의 기존 예외는 유지했다.
- 미결정 목록에서 가중치 값의 상한과 응모권 사용 수량 상한을 구분했다.
- 변경 전후는 [ADR-010](../03-decisions/010-five-ticket-entry-limit.md)에 기록했다.

## 확인 및 다음 작업

- 변경 문서의 공백 오류와 기존 '여러 장' 표현 잔존 여부를 확인했다.
- getddo-be, 코드, DDL은 수정하지 않았다. PR은 생성하지 않았다.
- 후속 구현 시 실제 ERD의 1회 응모 상한 컬럼과 이벤트별 누적 상한을 혼동하지 않도록 한다.
