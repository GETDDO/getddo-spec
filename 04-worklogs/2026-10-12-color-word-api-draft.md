# 글자색깔 맞추기 API 연동 초안

- 상태: 검토 대기
- 요청: 확정된 색깔 게임 규칙을 바탕으로 프론트·백엔드 연동 초안 작성.

## 확인된 사실

- 현재 FE는 자체 문제 생성·일시정지·탭 이동 자동 정지를 제공하고, 종료 시 점수만 제출한다.
- [플레이 규칙](../02-domain/game.md#글자색깔-맞추기-규칙)은 사용자 확인으로 확정됐다.
- API·문제 생성·서버 검증·시간 경계·중도 종료·보상일 기준은 아직 계약 확인이 필요하다.

## 작성 내용과 영향

- 변경 전: 공통 G03/G04 DTO와 게임별 스키마의 후속 확인 항목만 있었다.
- 변경 후: [색깔 게임 연동 제안](../05-api/game-color-word-draft.md)에 시작/결과 예제, 문제 생성 재현, 답변 기록, 점수 판정, 재시도·보상 및 프론트 변경 위치를 작성했다.
- 공개 seed와 클라이언트 시간 기록의 한계를 명시하고 실제 플레이·매크로 판별을 보장하지 않는다고 구분했다.
- [게임 API](../05-api/game.md)와 [후속 사항](../00-requirements/pending-decisions.md#게임)에 검토 대기 초안으로 연결했다. 기존 API를 확정 계약으로 덮어쓰지 않았다.

## 검증과 다음 할 일

- JavaScript로 제안 seed의 첫 네 문제와 예제 점수·목숨·제한 시간의 정합성을 확인했다.
- 실제 FE/Java 코드 교차 검증이나 API 구현·테스트는 수행하지 않았다.
- 사용자·프론트 담당과 전송 방식·일시정지/중도 종료·보상일·운영 한도를 확인하고 GD-153에 채택 결과를 기록한다.
- 이번 변경은 로컬 초안이며 커밋·push 전이다.

## 후속 결정

2026-10-12 사용자가 명세 우선 및 추천안 적용을 확인했다. 이후 채택 반영 내용은 [별도 기록](2026-10-12-color-word-api-adoption.md)을 따른다. 위 내용은 초안 작성 당시 상태다.
