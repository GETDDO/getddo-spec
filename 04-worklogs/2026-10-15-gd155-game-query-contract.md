# 작업 기록: GD-155 게임 목록·상세 조회 계약

- 작성일: 2026-10-15
- 관련 이슈 / PR: GD-155 / PR 미생성
- 상태: 검토 대기 (Codex 작성, 담당자 확인 전)
- 영향 범위: 프론트엔드 / 백엔드

## 목적

FE가 임시 문자열 대신 DB UUID·code로 게임 목록에서 상세·시작까지 연결할 수 있도록 조회 계약의 미확정 부분을 정리한다.

## 한 일

- 최신 spec main `6a682f4`와 BE dev `412de2e7`, Jira GD-155와 개인 실행계획 G-02를 대조했다.
- 사용자는 비활성 게임 목록 제외·상세 404, 시작 지원 여부와 무관한 활성 게임 전체 목록, 색깔 공개 5개 규칙·타꼬런 상세 후속/409를 각 추천 선택지로 명시 확인했다.
- 위 선택을 [게임 조회 계약](../05-api/game.md#g01g02-조회-계약--2026-10-15-사용자-선택)에 기록했다. 기존 code 정렬과 공통 사용자 문맥·응답·시계를 재사용한다.

## 확인된 내용

- 색깔 G03/G04 및 다른 담당자의 사용자·지급·추첨 계약은 변경하지 않는다.
- 타꼬런 안내가 목록에 보여도 상세·시작 지원 완료를 뜻하지 않는다. 전체 게임 공개 원칙과 상세 규칙 미확정 상태를 구분한다.
- 백엔드 운영 코드·단위/MVC/MySQL 통합 테스트 소스 컴파일이 최종 작업 폴더에서 성공했다(2분 22초). 사용자 실행 방침에 따라 로컬 테스트·전체 빌드는 실행하지 않았으며 FE 반영·운영 DB 적용도 미확인이다.

## 다음 할 일

- 사용자가 단위/MVC·MySQL 통합 테스트 성공을 확인했다. 실제 FE 연동은 별도 확인이 필요하다.
- 사용자 PR 공유 요청에 따라 승인된 spec 조회 계약을 main에 반영하고 백엔드 PR에서 연결한다.

## 미결정·차단 사항

- 타꼬런 상세 공개 규칙·시작·판정 계약은 별도 작업에서 확정한다.
- 게임 행 자동 등록, 관리자 게임 CRUD, 결과·보상·통계는 이번 조회 구현 범위가 아니다.

## 반영 결과

- 변경한 명세: [게임 API](../05-api/game.md)
- 관련 ADR: 없음. 조회 정책의 사용자 선택을 해당 API 원본에 반영했다.
- 관련 PR: GD-155 백엔드 PR 생성 후 실행계획과 PR 본문에 연결한다. spec은 AGENTS.md에 따라 별도 PR 없이 main에 직접 반영한다. 실제 FE 반영 완료를 뜻하지 않는다.

## 공유 전 확인

사용자가 “통과했어”라고 관련 테스트 성공을 확인하고 “피알올려줘 라벨도 그렇고”라고 공유를 요청했다. 백엔드 작업 폴더에 남은 GameQueryApiIntegrationTest 보고서는 tests=4, failures/errors/skipped=0이다. 단위/MVC 실행 성공은 사용자 확인을 근거로 하며 전체 test/build·FE 연동 성공으로 확대하지 않는다. 승인된 조회 정책·기존 G03/G04 유지·문서 링크와 diff를 대조했다.
