# GD-203 이벤트 추첨·발표 시각 계약 정리

- 날짜: 2026-10-15 KST
- 상태: 검토 대기 — Codex 작성 초안, 담당자 확인 전
- 관련: [GD-203](https://ureca4.atlassian.net/browse/GD-203)

## 목적과 확인된 결정

마감 +5분 자동 추첨과 관리자 확인 후 별도 수동 공개 정책을 유지한다. 사용자는 이벤트 API에 추첨 시각을 발표 예정 시각으로 내려주는 표현을 정리하고, 관련 spec도 최신화하도록 요청했다.

## 반영 내용

- `05-api/event.md`의 EventSummary에서 `publicationScheduledAt`을 제거했다. 이를 상속하는 EventDetail·AdminEvent에서도 제외한다.
- AdminEvent에만 `drawScheduledAt`을 추가해 마감 +5분의 자동 추첨 기준임을 명시했다. 사용자 응답에는 추첨/발표 예정 시각을 제공하지 않는다.
- 실제 `publishedAt`과 공개 여부는 기존 결과 조회 계약을 사용한다. 자동 추첨·확인·승인만으로 결과를 공개하지 않는다.
- 사용자 결정으로 이관된 이벤트 취소와 시작·마감 상태 전환의 담당 표기도 현재 경계에 맞췄다.

## 범위와 다음 작업

- 공용 원본: [이벤트 API](../05-api/event.md), [이벤트 규칙](../02-domain/event.md), [추첨 규칙](../02-domain/drawing.md).
- 새로운 도메인 정책이나 DB 스키마를 추가하지 않았다. 추첨·결과 조회 문서의 기존 수동 공개 결정을 변경하지 않았다.
- BE `feat/GD-203`에서 응답·테스트·문서를 반영한다. 프론트는 필드 제거/관리자 필드 추가를 맞춰야 한다. 이 문서 작성은 BE 배포나 프론트 연동 완료를 의미하지 않는다.
