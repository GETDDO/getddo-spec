# 공통 감사 조회 제외 및 기록 명세 정리

- 상태: 검토 대기 · Codex 작성 · 담당자 확인 전
- 요청: 공통 감사 조회를 제공하지 않으므로 조회 구현을 제거하고 감사 spec을 표로 정리한다.

## 반영 내용

[감사 기록 명세](../05-api/audit.md)에 제공 범위·기록 항목·저장 규칙·변경 전후를 표로 정리했다. [구현 범위](../00-requirements/scope.md)와 [ADR-024](../03-decisions/024-audit-recording-without-query.md)에 조회 제외와 기록 유지를 명시했다. API 목록·추첨·배너·미결정 문서에서 공통 감사 조회 제공 전제를 정리했다.

## 확인·후속

GD-207 PR #104는 확인 시점 미병합이었다. 조회 추가 파일을 제거하되 공통 감사 저장 코드·테스트·데이터는 유지한다. BE 검증 결과는 BE 감사 기록 문서와 [PR #104](https://github.com/Uplus-GETDDO/getddo-be/pull/104)에서 확인한다. 사용자 요청에 따라 이 명세를 main에 게시하고, BE PR은 감사 기록 유지와 공통 조회 제외 내용으로 갱신한다. FE 코드와 Jira는 이번 작업에서 변경하지 않는다. 과거 작업 기록을 현행 정책으로 사용하지 않는다.
