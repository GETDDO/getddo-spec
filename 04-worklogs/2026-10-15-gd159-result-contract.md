# GD-159 결과 오류·한도·지급 연결 계약

- 날짜: 2026-10-15
- 작성: Codex AI 초안 — 담당자 확인 전
- 상태: 검토 대기

## 목적

색깔 게임 결과 구현에 앞서 남아 있던 공개 오류·입력 상한·만료/보존 및 기존 지급 연결을 사용자 선택으로 구분한다.

## 사용자 확인

사용자는 추천안을 각각 선택했다.

1. 없는 플레이·타인 소유·게임 불일치·잘못된 토큰은 같은 404 GAME-005로 은닉한다.
2. 게임 청구·통계를 게임 영역에 구현하고 기존 지급 서비스는 내부 정책 변경 없이 같은 트랜잭션에서 호출한다.
3. 결과 본문 1MiB·답변 10,000개를 초과하면 413으로 거절한다. 초기 토큰 시간 만료·완료 결과 자동 삭제는 도입하지 않는다.
4. G05 초안의 필드를 채택하고 활성 일반 사용자의 본인 통계를 제공한다. 비활성 게임의 과거 통계는 조회할 수 있으며 없는 게임만 404로 처리한다.

기준 원문은 [색깔 게임 연동 계약](../05-api/game-color-word-draft.md)과 [G05 조회 계약](../05-api/game.md)이다. G04의 기존 U 권한과 정상 0점/미달 통계·하루 한 장·최초 재시도 결과 보존은 유지한다.

## 확인 결과와 다음 할 일

- BE에서 기존 판정기·플레이 저장·응모권 지급 서비스를 연결하는 코드를 작성하고 테스트 중이다. 이 기록은 구현 완료나 FE 반영 완료의 증거가 아니다.
- G05 내 통계 조회 계약도 사용자 확인을 받았다. 이번 선택으로 관리자 게임·타꼬런·어뷰징 탐지 세부 계약을 일괄 확정하지 않는다.
- 실제 FE 요청 형식·한도 초과 표시·202 재시도 연결, 차단·빈도 제한 담당자의 서비스 경계를 확인한다.
