# 작업 기록: 타꼬런 FE·BE 계약 정렬

- 작성일: 2026-10-16
- 관련 이슈 / PR: GD-158 / PR 미생성
- 영향 범위: 공통·프론트엔드·백엔드
- 작성: Codex
- 상태: 검토 대기

## 목적

FE 초안과 미게시 BE 구현의 차이를 정리하고, 사용자가 BE를 FE A안에 맞추도록 선택한 내용을 공용 기준에 반영한다.

## 한 일

- 변경 전에는 타꼬런 A/B 검증 방식을 검토 중으로 기록했고, FE 초안과 BE 개인 자료가 서로 달랐다.
- 변경 후에는 [타꼬런 계약](../05-api/game-takko-run-draft.md)과 [게임 도메인](../02-domain/game.md)에 사용자 채택 범위를 기록하고, [게임 API](../05-api/game.md)·[미결정 사항](../00-requirements/pending-decisions.md)에 같은 상태를 연결했다.
- FE 초안의 기존 파일 경로를 유지해 링크를 깨지 않았다. 타이밍·주문 초안과 그 미확정 정책은 변경하지 않았다.

## 확인된 내용

- 사용자: “내가 맞추자 전부 맞춰줘”. 타꼬런 FE A안에 BE를 맞추는 작업이다.
- 추가 질문: 활성10분 뒤 정상종료를 유지하고120Hz에 맞춰72,000tick으로 보완하는 추천안 선택.
- 추가 질문: 서버 경과시간 대조는 색깔 게임처럼 후속으로 남기고 재현·크기·tick 상한만 검사하는 추천안 선택.

## 다음 할 일

- 공용 문서의 상대 링크31개와 diff를 확인했다. 사용자가 BE 단위 테스트 성공을 알렸고 새 작업 폴더의 XML에서1,241개·실패/오류/스킵0을 확인했다. 에이전트는 테스트를 실행하지 않았다. 통합 테스트·전체 빌드는 사용자 선택에 따라 BE PR의 CI에서 확인한다.
- 명세 채택은 실제 FE 연결·Java/TS 교차 검증·운영 데이터 준비·배포 완료와 구분한다.
- BE 내부 코드·테스트 상세는 BE 저장소에서 관리한다. 공용 원격 게시와 담당자 공유 상태는 실제 수행 후 기록한다.

## 미결정·차단 사항

- 서버 경과시간 대조의 허용 오차는 후속 계약이다.
- 실제 FE 반영·공통 예제·운영 반영은 완료 확인 전이다.

## 반영 결과

- 변경한 명세: 타꼬런 계약, 게임 도메인, 게임 API, 미결정 사항.
- 관련 ADR: 새 ADR 없음.
- 관련 PR: 공용 명세는 main 직접 반영 방식으로 게시한다. BE는 GD-158 기능 PR로 연결하며 공용 계약 게시가 FE·DB·배포 완료를 뜻하지 않는다.
