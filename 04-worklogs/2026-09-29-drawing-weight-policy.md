# 작업 기록: 추첨 가중치 정책 확정 설계

- 작성일: 2026-09-29
- 관련 이슈 / PR: [GD-36](https://ureca4.atlassian.net/browse/GD-36) / PR 미생성
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

추첨 선정 설계에 필요한 응모권 수의 가중치 환산식, 가중치 값 상한 및 추가 배율을 정한다.

## 한 일

- 사용자가 선형 환산, 별도 가중치 상한 없음, 추가 배율 없음을 선택했다.
- 기존 일반 이벤트의 응모권 누적 사용 상한 5장 및 월말 소진용 이벤트 예외와 새 결정을 대조했다.
- [추첨 도메인 규칙](../02-domain/drawing.md#가중치-및-중복-당첨), [공용 ADR-013](../03-decisions/013-linear-drawing-weight.md), 미결정 목록과 추첨 API 초안의 가중치 설명을 정리했다.

## 확인된 내용

- 일반 가중치 적용 이벤트의 응모권 사용 상한은 사용자당 이벤트별 누적 5장이다. 월말 소진용 이벤트에는 사용 수량 상한이 없다. 기준은 [응모권 규칙](../02-domain/ticket.md)이다.
- 당첨 확률을 사용자에게 표시하지 않는 정책은 [기능 요구사항](../00-requirements/functional-requirements.md)을 따른다.

## 다음 할 일

- [ ] 담당자와 관련 기능 담당자가 정책 반영 및 연동 경계를 검토한다.
- [ ] 실제 차감 수량과 추첨 가중치가 공용 정책대로 반영되는지 연동 검증한다.

## 미결정·차단 사항

- 추첨 결과를 확정하지 못했을 때의 사용자 안내와 운영상 복구 기준은 별도 결정이 필요하다.
- 월말 소진용 이벤트의 운영 허용 조건은 이벤트 담당자가 정한다.
