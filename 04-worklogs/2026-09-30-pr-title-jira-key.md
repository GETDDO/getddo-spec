# 작업 기록: PR 제목의 Jira 이슈 키 형식 정리

- 작성일: 2026-09-30
- 관련 이슈 / PR: 별도 이슈 없음 / PR 미생성
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자가 요청한 PR 제목 검사와 현재 Jira 사용 방식에 맞춰 공용 제목 규칙을 정리한다.

## 한 일

- 변경 전에는 PR 제목에 GitHub 이슈 번호를 사용했다.
- 사용자가 spec 수정도 포함한 Jira 형식 통일을 명시적으로 선택하여 [PR 제목 규칙](../01-conventions/pull-request.md#pr-제목)과 예시를 변경했다.
- 허용 타입은 기존 [커밋 규칙](../01-conventions/commit.md)을 참조한다.

## 확인된 내용

- 공용 제목 규칙은 프론트엔드와 백엔드 PR 작성에 적용된다.
- CI 구현과 필수 상태 검사 설정은 각 코드 저장소에서 관리한다. 이번 요청으로 프론트엔드 CI를 변경하지 않았다.
- PR 본문 템플릿과 공개 API 계약은 변경하지 않았다.

## 다음 할 일

- [ ] 공용 제목 규칙 변경을 검토하고 공유한다.
- [ ] 각 코드 저장소에서 제목 검사의 적용 및 필수 상태 검사 설정을 확인한다.

## 미결정·차단 사항

추가로 결정한 PR 본문 검사 규칙은 없다.
