# 작업 기록: 플래티넘 응모권 공용 스펙 반영

- 작성일: 2026-10-17
- 관련 이슈 / PR: 미지정 / PR 미생성
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자가 확인한 플래티넘 등급과 획득 확률·가중치를 공용 스펙에 반영한다.

## 한 일

- 응모권 확률표, 추첨 합산식·예시, 용어와 응모권·응모·미션·추첨 API의 등급 표현을 갱신했다.
- 기존 ADR-014를 보존하고 ADR-025와 연결했다.
- 서비스 적용 시점과 구현·화면 연동 검증을 후속 사항으로 구분했다.
- `git diff --check`와 변경 diff를 검토하고, 등급 4종·확률 합계 100%·가중치 1/3/5/10 및 수정 문서의 상대 링크 대상 존재 여부를 검증했다. 모두 통과했다. 문서만 변경해 애플리케이션 테스트·빌드는 실행하지 않았다.

## 확인된 내용

- 확정 확률·가중치의 원본은 [응모권 규칙](../02-domain/ticket.md#게임미션-보상의-등급-추첨)이며 확률 합계는 100%다.
- 명세 수정 단계에서 백엔드와 공용 스펙 저장소의 원격 조회는 DNS 오류로 실패해 로컬 문서를 기준으로 작업했다. 이후 사용자 푸시 요청에 따라 공용 스펙 원격 fetch에 성공했고 새 커밋 4개의 변경 내용을 확인했다. 응모·미션 API의 별도 절 추가와 API 목록 변경이다.
- 양쪽 저장소의 기존 미커밋 변경을 보존하고 pull하지 않았다. 명세 수정 단계에서는 커밋·push를 수행하지 않았다. 이후 사용자가 푸시를 요청했다. 구현 코드·DB 변경은 수행하지 않았다.

- 서비스 적용 시점과 기존 운영 정책 전환은 [등급 응모권 후속 사항](../00-requirements/pending-decisions.md#등급-응모권)에 남겼다.
- 공용 스펙 수정만 수행하므로 플래티넘 지원 구현·연동 완료를 검증하지 않았다.
