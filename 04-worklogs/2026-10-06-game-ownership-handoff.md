# 작업 기록: 전민규 게임 담당 범위 정리

- 작성일: 2026-10-06
- 관련 이슈 / PR: 미지정 / PR 없음
- 상태: 완료 — 전민규 담당 범위 반영, 다른 담당자 재배분은 협의안
- 영향 범위: 백엔드 담당 경계·공용 API 협의

## 목적

업무 재배분 논의에서 전민규가 기존 알림·배너를 유지하고 게임 기능을 추가로 맡기로 한 사용자 지시를 공용 명세의 담당 표기에 반영한다. 기능 정책이나 미확정 API 필드를 새로 결정하지 않는다.

## 확인한 담당 범위

- 전민규: 사용자 게임 G01~G05와 관리자 게임 AG01~AG03. 게임 종류·공개 규칙·결과 검증 입력을 설계하고, 서버 판정·플레이/점수/개인 통계·게임별 KST 일일 보상 자격을 구현한다.
- 전민규: 기존 사용자·관리자 알림 N01~N03/AN01~AN05, 알림 생성·모의 발송·재시도 및 배너 B01/AB01~AB05를 유지한다.
- 윤태형의 응모권 기능: 게임이 판정한 보상 자격을 받아 확정 등급·실제 1장 지급·지갑·원장·회수를 처리한다. 전민규의 게임 기능은 지급 결과를 연결하고 같은 게임·사용자·KST 보상일에 중복 지급되지 않도록 조율한다.
- 석종수의 검토 기능: 게임 부정 의심을 검토·확정한다. 확인된 플레이의 점수·통계 무효화는 전민규의 게임 기능, 부정 지급분 회수는 윤태형의 응모권 기능과 연계한다.

## 다른 재배분의 상태

이전 균등 배분 논의에서 이벤트 상태 운영을 박지훈, 미션을 박지훈, 여러 도메인의 관리자 API를 각 기능 담당자에게 옮기는 안을 제안했다. 이 항목들은 해당 담당자의 수락과 인수 범위가 확인되지 않아 이번 문서에서 확정하거나 기존 API 담당 표기를 바꾸지 않는다. 전민규가 게임을 추가로 맡는 작업량을 판단할 때 이 이관 여부를 함께 확인해야 한다.

## 다음 할 일

- [ ] 게임 종류·서버 검증 데이터·자정을 걸친 플레이 보상일 기준을 전민규가 설계하고 공유한다.
- [ ] 전민규·윤태형이 게임 보상 자격과 등급 응모권 지급의 트랜잭션·중복 방지 경계를 맞춘다.
- [ ] 다른 담당자 재배분을 팀에서 확인한 뒤 백엔드 담당자 문서와 남은 API 담당 표기를 함께 갱신한다.
