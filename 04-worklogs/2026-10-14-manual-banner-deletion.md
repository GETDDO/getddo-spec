# 작업 기록: 이벤트 연결 배너 수동 삭제 정책 최신화

- 작성일: 2026-10-14 (KST)
- 작성자: Codex — 사용자 정책 확인 반영
- 관련 이슈 / PR: GD-61 / PR 미생성
- 상태: 검토 대기
- 영향 범위: 프론트엔드·백엔드 이벤트·배너 관리

## 목적

사용자가 확정한 배너 수동 삭제 방침과 공용 이벤트 규칙·API·ADR 사이의 차이를 정리한다. 알림 정책은 이번 변경 범위에서 제외한다.

## 한 일

- 이벤트 규칙과 API의 배너 자동 삭제 문구를 관리자 수동 삭제로 변경했다.
- ADR-021에 변경 전후와 영향을 기록하고 ADR-012의 배너 정책만 부분 대체했다.
- 기존 자동 삭제 결정 기록을 보존하고 후속 ADR 링크를 추가했다.

## 확인된 내용

- 변경 전: 이벤트 삭제 시 연결 배너도 자동 삭제한다.
- 변경 후: 배너는 관리자 수동 삭제이며 배너가 남아 있어도 이벤트 삭제를 제한하지 않는다.
- 삭제 가능 조건과 취소·삭제의 알림 정책은 변경하지 않았다.
- 변경 문서의 상대 링크와 `git diff --check`를 확인했다. 새 ADR은 사용자 재확인에 따른 정책 결정이며 코드 구현·테스트의 완료를 뜻하지 않는다.
