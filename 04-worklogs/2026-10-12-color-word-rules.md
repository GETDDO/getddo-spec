# 글자색깔 맞추기 플레이 규칙 확정 반영

- 상태: 검토 대기
- 목적: 담당자가 채택한 현재 게임 규칙을 프론트·백엔드 공통 기준으로 기록한다.

## 확인된 사실과 변경

- 사용자가 기존 규칙 설명에 “응 그 규칙 그대로 가자”라고 확인했다.
- 변경 전: 공용 게임 문서에 게임별 점수·종료 규칙이 없고 담당자 후속으로 남아 있었다.
- 변경 후: [게임 도메인](../02-domain/game.md#글자색깔-맞추기-규칙)에 색깔 게임의 확인된 규칙을 기록하고 [후속 사항](../00-requirements/pending-decisions.md#게임)에서 확정된 규칙과 미확정 계약을 구분했다.
- Jira GD-153·GD-157에 규칙 확인과 남은 설계 범위를 반영한다. 규칙 확정은 코드 구현 완료를 의미하지 않는다.

## 영향과 다음 할 일

- 프론트는 현재 플레이 규칙을 기준으로 유지하고 서버 검증에 필요한 입력 전달 계약을 맞춘다.
- 백엔드는 같은 규칙으로 점수를 판정하도록 구현하되, 문제 생성·검증 근거·시간 경계·일시정지·중도 종료 처리는 별도 설계한다.
- 타꼬런 검증 방식과 공개 API 계약은 이번 확인으로 확정하지 않는다.
- 이번 변경은 문서 반영이며 애플리케이션 코드 변경·테스트 실행은 없다.
