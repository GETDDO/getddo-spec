# 작업 기록: 응모권 보상 수량 하한 확정

- 작성일: 2026-09-29
- 관련 이슈 / PR: [GD-39](https://ureca4.atlassian.net/browse/GD-39) / PR 미생성
- 상태: 검토 대기
- 영향 범위: 공통 / 백엔드

## 목적

출석·미션 보상으로 지급하는 응모권 수의 하한을 정한다. 기존에는 하한이 없었고 API 초안이 0장을 허용하고 있었다.

## 한 일

- 보상 수량을 1장 이상으로 정했다. 게임 보상은 기존대로 항상 1장이다.
- [응모권 규칙](../02-domain/ticket.md), [출석 규칙](../02-domain/attendance.md), [미션 규칙](../02-domain/mission.md)에 하한을 반영했다.
- [출석 API 초안](../05-api/attendance.md)의 `MilestoneWrite`와 일일 정책 등록, [미션 API 초안](../05-api/mission.md)의 `MissionWrite`와 미션 등록 오류 표기를 바꿨다.

## 확인된 내용

- 변경 전: 관리자가 보상 수량을 수정할 수 있다는 규정만 있고 하한이 없었다. 출석 API 초안은 단계 보상을 `≥0`으로 적었다.
- 변경 후: 출석·미션 보상 수량은 1장 이상이다.
- 이유: 응모권 지급 이력은 수량이 0인 지급을 기록하지 않는다. 0장 보상을 허용하면 관리자가 저장할 때는 통과하지만 사용자가 그 보상에 도달한 시점에 지급을 기록할 수 없어 출석·미션 처리가 실패한다.
- 백엔드 스키마는 같은 하한을 제약으로 이미 적용했다.
