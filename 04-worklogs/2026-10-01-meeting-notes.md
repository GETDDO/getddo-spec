# 회의 추가사항 메모

- 상태: 검토 대기
- 아래 내용은 전달받은 회의 메모이며, 기존 기준 문서와 코드·설정에는 반영하지 않음.

1. DTO 변환 로직
    - 별도 Mapper를 도입하지 않는다.
    - 기존 구조에 변환 메서드를 추가하는 방식으로 처리한다.

2. 예외 처리
    - 예외를 정의하거나 처리할 때 관련 ErrorCode도 함께 구성한다.
    - 에러 코드와 Exception을 연계하는 방식으로 통일한다.

3. YAML 설정 파일 관리
    - GitHub에 올라간 application.yaml, local.yaml을 저장소에서 제거하고 .gitignore에 추가한다.
    - 실제 적용 전에는 공통 설정의 제공 방식과 로컬·배포 환경의 설정 전달 방법을 확인해야 한다.

4. Lombok 사용
    - Lombok을 사용하기로 한 만큼, 직접 작성한 getter 등 Lombok으로 대체할 수 있는 반복 코드는 어노테이션을 활용한다.

5. 불필요한 주석 정리
    - 예외 메시지나 코드 자체로 의미가 충분히 전달되면 같은 내용을 설명하는 주석은 추가하지 않는다.
    - 코드만으로 알기 어려운 이유나 의도를 설명하는 주석은 유지한다.

6. PR 리뷰 방식
    - CodeRabbit 리뷰와 함께 사람이 직접 리뷰하도록 한다.
    - PR 병합 조건에 최소 1명의 사람 리뷰어 승인을 포함한다.
