# 작업 기록: 이벤트 중단·재개 기능 제외

- 작성일: 2026-10-06
- 관련 이슈 / PR: 미지정 / PR 없음
- 상태: 완료 — 공용 명세 반영
- 영향 범위: 이벤트 운영·응모·응모권·알림·이벤트 API

## 목적

사용자 지시에 따라 이벤트 일시 중단·재개와 중단 시간을 요구사항에서 제외한다. 최종 취소와 차감 응모권 반환은 유지한다.

## 변경 전과 변경 후

- 변경 전: 이벤트를 일시 중단·재개하고, 중단 중 마감 시 자동 취소했다. API 초안에는 중단·재개 경로와 중단 관련 응답 필드가 있었다.
- 변경 후: 이벤트를 일시 중단하거나 재개하지 않는다. 중단 시간 설정과 중단 관련 응답 필드도 제공하지 않는다. 관리자 취소와 반환은 유지한다.

## 확인한 영향

- 공용 요구사항·이벤트 규칙·용어와 응모·응모권·알림 규칙에서 이벤트 중단 관련 내용을 정리했다.
- 이벤트 API 초안에서 AE06·AE07을 제외하고 AE08 취소 ID는 유지했다. 응모 API의 중단 오류 표현도 제거했다.
- 현행 백엔드 DB/코드에는 `SUSPENDED`, `suspended_at`, `suspended_from_status`가 남아 있다. 이 저장소에서는 DB와 코드를 변경하지 않았다.
- 추첨 실행의 장애 후 재개는 이번 이벤트 운영 변경과 관계없다.
