# 작업 기록: 이벤트 검색·입력 상한·취소 재요청 계약 최신화

- 작성일: 2026-10-16 (KST)
- 관련 이슈 / PR: 기존 GD-59·GD-60·이벤트 취소 구현 계약 정렬, 새 이슈·PR 없음
- 상태: 검토 대기 — 담당자 확인 전
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

현재 BE 동작과 다르게 남아 있거나 누락된 이벤트 API 계약 세 가지를 최신화한다. 새로운 기능이나 정책을 추가하는 작업이 아니라 기존 결정과 구현을 공용 문서에 반영하는 작업이다.

## 한 일

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 관리자 기간 검색 | 공통 `instant`·`[from,to)` 규칙만 있고 이벤트 예외가 없음 | [관리자 이벤트 기간 검색](../05-api/event.md#관리자-이벤트-기간-검색)에 KST 날짜 양끝 포함·모집 기간 겹침 조건과 예시를 명시하고 공통 문서에서 연결 |
| 입력 바이트 상한 | 이벤트·경품 설명과 취소 사유의 상한이 없음 | [등록·수정](../05-api/event.md#이벤트경품-동시-등록-및-수정)과 [상태 운영](../05-api/event.md#상태-운영)에 각 필드의 UTF-8 65,535바이트 상한과 초과 오류를 명시 |
| 취소 재요청 | 상태 무관 취소와 반환 중복 방지만 있고 재요청 응답이 없음 | [상태 운영](../05-api/event.md#상태-운영)에 이미 취소된 이벤트는 409 `EVENT-017`, 재처리 없음으로 명시하고 도메인 규칙의 취소 가능 상태 표현을 정렬 |

## 확인된 내용

- 변경 전 spec `main`과 BE 현재 브랜치에 `origin/dev`를 각각 pull했으며 모두 최신 상태였다.
- BE `dev`의 `88833cef9971068d8042bb4fd7078db3da65f381` 기준으로 날짜 요청 DTO·조회 서비스·저장소 조건, 설명 검증, 취소 서비스와 오류 코드를 대조했다.
- 프론트엔드는 관리자 날짜 쿼리를 KST 날짜로 전달하고, 입력 제한을 글자 수와 구분하며 취소 재요청의 409를 처리할 수 있도록 위 기준 문서를 따른다.
- 이미지 업로드·URL 연동은 이번 변경 범위에 포함하지 않는다.
