# 작업 기록: 게임·미션의 무작위 등급 응모권 정책 반영

- 작성일: 2026-10-06
- 관련 이슈 / PR: 미지정 / PR 미생성
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자가 확인한 게임·미션의 등급 응모권 지급 정책을 명세에 반영하고 ERD 변경 검토 범위를 구분한다.

## 한 일

- 브론즈 80%·실버 18%·골드 2%와 등급 응모권 1장·장당 가중치 1·3·5 의미를 사용자에게 확인했다.
- 원격 main의 최신 문서를 별도 작업 폴더에서 확인하고 원본에 적용할 정책 변경만 분리해 요구사항·응모권·게임·미션·응모·추첨 규칙과 용어를 갱신했다.
- API 초안의 갱신 필요 부분과 미결정 항목을 기록하고 ADR을 제안 상태로 작성했다.
- 백엔드 ERD의 보상 청구·지갑·원장·응모·추첨 후보 구조를 검토했다. ERD와 구현 코드는 수정하지 않았다.

## 확인된 내용

- 실제 장수와 추첨 가중치는 서로 다른 값이다. 기준은 [응모권 규칙](../02-domain/ticket.md), [추첨 규칙](../02-domain/drawing.md)이다.
- 기존 원본 spec 작업 폴더는 원격보다 뒤이고 미추적 `.idea`가 있어 pull하지 않고 보존했다.
