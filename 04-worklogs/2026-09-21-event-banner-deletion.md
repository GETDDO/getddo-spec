# 이벤트 삭제 시 연결 배너 처리 확정

- 상태: 완료
- 목적: 이벤트 삭제 시 연결된 배너의 처리 방식을 확정한다.

## 변경 전과 변경 후

- 변경 전: 연결된 배너를 함께 삭제할지, 이벤트 삭제를 제한할지 미정이었다.
- 변경 후: 사용자 결정에 따라 [이벤트 도메인 규칙](../02-domain/event.md)에 배너 처리 정책을 반영했다. 기존 이벤트 삭제 가능 조건은 유지한다.
- 알림 신청 관련 미결정 항목은 사용자 요청으로 제거했다. [기존 알림 정책](../02-domain/notification.md#이벤트-시작-알림)은 별도 신청 없이 응모 자격을 충족하는 사용자 전원에게 전송하도록 정의되어 있다.

## 수행 내용과 영향

- [배너 요구사항](../00-requirements/functional-requirements.md#13-배너)에 도메인 규칙 링크를 추가했다.
- 백엔드는 이벤트 삭제 처리에 연결된 배너 삭제를 반영해야 한다.
- 프론트엔드는 이벤트 삭제 후 배너 목록과 사용자 화면의 배너 표시를 갱신해야 한다.
- 이번 작업은 공용 명세 반영이며 코드 구현은 포함하지 않는다.

## 미결정 사항과 다음 할 일

- 알림 신청 삭제 처리에 관한 미결정 사항은 없다.
- 각 코드 저장소에서 확정된 정책의 구현 여부를 확인한다.

## 관련 문서

- 반영 문서: 위 도메인 규칙, 배너 요구사항, 미결정 사항.
- 관련 ADR: 없음.
- Pull Request: 생성하지 않음.
