- 작성일: 2026-10-12

- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자가 확정한 관리자 사유의 개별 취소·빈 자리 재추첨과 응모권 반환·회수 없음 정책을 spec에 반영해 기존 취소 사유 제한과 Jira 계획의 차이를 정리한다.

## 한 일

요구사항·범위·추첨·응모권·후속 확인 및 추첨·어뷰징·응모권 API 초안의 충돌 문구를 수정했다. ADR-019를 작성하고 ADR-018에서 후속 결정으로 연결했다. 전체 당첨 취소·전체 재추첨은 추후 추가 예정으로 기록했다. 알림 문서·백엔드 코드·HTML은 수정하지 않았다.

## 확인된 내용

작업 전 spec main 로컬·원격은 fca7d6e로 동일하고 작업 트리가 깨끗했다. backend 로컬 dev는 원격과 분기되어 사용자 지시에 따라 보존했고 원격 dev는 0faf75e였다. 사용자 정책 확정과 API·코드·문서 검토 상태를 구분한다. 기준은 [추첨 규칙](../02-domain/drawing.md#재추첨)과 [응모권 규칙](../02-domain/ticket.md#응모권-회수-제외)이다.
