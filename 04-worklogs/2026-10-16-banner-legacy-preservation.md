# GD-209 이전 배너 보존 계약 확인

- 상태: 검토 대기 · Codex 작성 · 담당자 확인 전
- 목적: 기존 배너 유무가 미확인인 상태에서 기존 URL·행을 지키는 이전 계약을 정리한다.

## 확인한 사실

사용자가 “추천 방식 적용 — 기존 행 보존, 미연결 배너는 관리자만 확인”을 선택했다. [배너 API](../05-api/banner.md)에 관리자 응답 eventId null 예외와 신규 입력 필수 유지, 미연결 사용자 숨김을 반영했다. [배너 규칙](../02-domain/banner.md)에서 해당 기준을 연결했다.

## 구현·검증 경계

BE feat/GD-209에 새 마이그레이션·카탈로그 순서 저장·감사 원자성·이전 행 보존 테스트를 작성했다. 사용자가 테스트 성공을 알려준 뒤 결과 파일에서 배너 API12개와 V027→V028 이전1개의 성공을 확인했다. 테스트는 사용자가 실행했으며, 이번 에이전트는 재실행하지 않았다. 이는 실제 운영 DB 조사·이미지 업로드·FE 연동·배포 완료를 뜻하지 않는다.

## 다음 할 일

승인된 이전 데이터 예외를 spec main에 게시하고 BE PR에서 함께 검토한다. 실제 공유DB의 기존 행과 CDN 주소·키는 담당자 후속 확인 대상이다.
