# 2026-10-16 타꼬런·타꼬 타이밍·타꼬 주문 검증 계약 초안

## 목적

색깔 게임 외 게임의 서버 판정 계약이 없어, 프론트에 구현된 규칙을 기준으로 G03 `gameData`·G04 `validationData` 초안을 정리한다.

## 수행 내용

- 프론트 규칙 코드(getddo-fe `src/features/playGame/model`)와 명세를 비교했다.
- 초안 3개 작성: [타꼬런](../05-api/game-takko-run-draft.md), [타꼬 타이밍 맞추기](../05-api/game-takko-timing-draft.md), [타꼬 주문](../05-api/game-takko-order-draft.md).
- 공통 흐름·재시도·결과·오류는 [색깔 게임 연동 계약](../05-api/game-color-word-draft.md)을 따르는 것으로 제안하고, 게임별로 다른 부분만 적었다.

## 확인된 사실

- 타꼬런 400점은 프론트 스테이지 2 시작 점수와 같다.
- 글자색깔 맞추기의 점수·목숨·제한 시간·문제 생성 규칙은 프론트와 명세가 같다.
- 타꼬 타이밍 맞추기·타꼬 주문은 프론트에만 있고 도메인 규칙·최소 보상 점수가 없다.
- 타꼬런은 화면 프레임마다 다른 시간 간격으로 진행해, 같은 입력이어도 기기마다 점수가 조금씩 달라진다.

## 다음 할 일과 미결정 사항

- 두 게임의 규칙·최소 보상 점수 확정, 타꼬런 A안/B안 선택: [미결정 사항](../00-requirements/pending-decisions.md#게임).
- 백엔드 전민규 검토 후 채택 범위를 도메인 규칙에 반영한다.
