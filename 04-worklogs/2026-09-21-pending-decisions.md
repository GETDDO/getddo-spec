# 미결정 사항 순차 확정 및 일괄 반영

- 작성자 / 날짜: Codex / 2026-09-21
- 상태: 검토 대기
- 관련 PR: 생성 후 연결

## 목적과 진행 방식

미결정 사항을 위에서부터 선택지로 확인했다. 첫 반환 결정은 즉시 반영했고 이후 사용자 요청에 따라 답변을 모아두었다가 ‘끝났다’ 지시 후 일괄 반영했다. 이후 PR 생성·머지도 요청받았다.

## 반영 내역

- [기능 요구사항](../00-requirements/functional-requirements.md), [구현 범위](../00-requirements/scope.md), [용어](../02-domain/glossary.md)를 최종 답변에 맞췄다.
- [이벤트](../02-domain/event.md): 기존 응모 유지·시각 기준 재개, 마감 후 중단 즉시 취소, 취소와 반환 함께 완료.
- [응모권](../02-domain/ticket.md), [응모·어뷰징](../02-domain/entry.md): 반환분 익월까지, UTC 만료 경계, DB 확정 기준, 탐지·제한 적용과 담당자 수정 구분.
- [미션](../02-domain/mission.md): 최종 정정에 따라 반복을 제거하고 관리자 수동 신규 등록·미션별 1회 완료로 변경. 오답 재도전은 무제한 유지.
- [출석](../02-domain/attendance.md), [게임](../02-domain/game.md): UTC 보상 기준, 게임 재제출 멱등성, 출석 단계·수량 수정과 적용 시점.
- [추첨](../02-domain/drawing.md): 미검토 포함 즉시 추첨, 확정 부정 당첨자만 재추첨, 후보·가중치·관리자 연출·상태, 5년 운영 보관, 공개 항목 변경.
- [알림](../02-domain/notification.md): 시작 10분 전, 생성 시점 자격, 예약 갱신·취소, 기존 수신자 변경 안내, 결과 확인·변경 당사자 알림.
- [ADR-008](../03-decisions/008-finalized-service-policies.md)에 변경 전후와 최종 선택을 기록하고 기존 ADR은 후속 결정 링크로 연결했다.
- 주간 미션 보류 목록과 출석의 주간 미션 중복 질문을 삭제했다. 관리자 사용자 정보 수정과 탈퇴 기능은 제외했다.
- [미결정·담당자 후속 목록](../00-requirements/pending-decisions.md)을 재작성했다. 어뷰징 담당자 수치 변경은 정책 미결정이 아니다. 가중치·누락 원문은 보류하며 게임·마스킹·배너는 담당자 후속 작업이다.
- 개인정보 파기 시 익명화·집계 중 어느 방식인지 사용자가 선택하지 않았으므로 확정하지 않았다. 탈퇴 기능 없음과 개인정보 보관 의무를 구분했다.
- 백엔드 논리 테이블 설계는 별도 저장소의 `docs/03-database/reward-tables.md`에 반영했다. 실제 DDL·API는 구현하지 않았다.

## 검증

- `git diff --check`: 문서 공백 오류 확인.
- 로컬 Markdown 파일·제목 링크 검사: 삭제한 미결정 제목을 참조하던 작업 기록 링크를 수정하고 전체 재검사.
- 현행 요구사항·도메인·설계에서 반복 미션, 후속 반환, 검토 대기 추첨, 닉네임 공개 및 사용자 정보 수정의 오래된 정책이 남아 있는지 대조했다.
- 문서 작업이므로 애플리케이션·DB 동작 테스트는 수행하지 않았다.
