# 작업 기록: 사용자 알림 N01~N03 API 계약 확정

- 작성일: 2026-09-30
- 관련 이슈 / PR: [GD-65](https://ureca4.atlassian.net/browse/GD-65), [백엔드 PR #7](https://github.com/GETDDO/getddo-be/pull/7)
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드
- 작성: Codex

## 목적

사용자가 요청한 현재 구현 기준 N01~N03 계약 확정을 공용 명세에 반영한다.

## 한 일

- 변경 전: 사용자·관리자 알림 API 전체가 담당자 확인 전 초안이었다. 타인 알림 오류는 403/404 중 미정이었다.
- 변경 후: 사용자 지시에 따라 N01~N03의 호출 경로·메서드·입출력·페이징·읽음 처리·오류 계약을 확정했다. 관리자 알림은 검토 대기로 유지했다.
- API 문서의 인덱스에서 확정 범위를 표시하고, 공통 사용자 처리의 남은 담당자 작업을 미결정 사항에 기록했다.
- 프론트엔드는 확정된 목록·커서·읽음 응답과 오류로 연동한다. 실제 프론트엔드 코드 대조·연동 테스트는 이번 문서 작업에서 수행하지 않았다.
- 기존 백엔드 공개 동작을 문서화했으며 백엔드 코드는 변경하지 않았다.

## 확인된 내용

- 확정 기준은 [사용자 알림 계약](../05-api/notification.md#사용자-알림--n01n03-확정)이다. 사용자의 2026-09-30 “확정해 그냥 spec 부분도 확정해버려” 지시를 근거로 반영했다.
- 원격 spec main은 `5189b7c6b59f81f9a33cc4a7b3111f7274356b15`로 로컬 HEAD와 같았다. 기존 미추적 `.idea/`를 보존하고 pull하지 않았다.
- 원격 백엔드 dev는 `e6e924112ab0a8819fd74e3792ea92a158df7fed`다. 직전 로컬 기준 이후 원격 비교에서 알림 코드 변경은 없었으며 관련 Controller·DTO·Service·Repository와 공통 응답 모델을 대조했다. 기존 DB README 변경을 보존했다.
- 코드 리뷰 완료나 공통 사용자 통합 완료를 이번 계약 확정으로 표시하지 않았다.
- 문서 diff의 공백 검사와 상대 링크·앵커 48개 검증을 통과했다. 문서만 변경하여 테스트·빌드는 실행하지 않았다.
- 사용자가 커밋·푸시·PR 생성을 명시적으로 요청하여 이번 작업은 spec 기본 직접 반영 규칙 대신 `docs/GD-65`에서 `main` 대상 PR로 제출한다.
