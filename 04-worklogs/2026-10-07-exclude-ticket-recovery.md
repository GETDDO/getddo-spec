# 작업 기록: 응모권 회수 기능 제외

- 작성일: 2026-10-07
- 관련 이슈 / PR: GD-93 / https://github.com/GETDDO/getddo-be/pull/26
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자가 확정한 회수 제외 정책에 맞춰 공용 명세와 GD-93 ERD 설명의 충돌을 해소한다.

## 한 일

- 구현 범위·요구사항·응모권·게임·응모 규칙에서 부정 획득분 회수 기능을 제외했다.
- API 초안의 AR04·AR05와 회수 DTO, 신규 REVOKE 이력 유형과 회수 알림 유형을 제외했다. 번호는 참조를 위해 남겼다.
- 등급 모델 후속 항목에서 회수 모델을 제외하고 ADR에 변경 전후와 영향을 기록했다.

## 확인된 내용

- 사용자가 회수 제외를 명시적으로 확정했다. 기준은 [응모권 규칙](../02-domain/ticket.md#응모권-회수-제외)이다.
- 취소·제외에 따른 반환과 점수 무효화·당첨 취소·재추첨은 유지한다.
- 문서만 변경했으며 기존 DB 데이터·Flyway·운영 코드는 변경하지 않았다.

## 다음 할 일

- [ ] 담당자가 제외된 API·화면·알림과 기존 저장 이력의 호환 처리를 확인한다.
- [ ] GD-93 구현 시 반환과 회수가 섞이지 않는지 확인한다.

## 미결정·차단 사항

회수 제외 정책은 확정됐다. 등급 선택·반환 등급·기존 지급분 전환은 [미결정 사항](../00-requirements/pending-decisions.md)을 따른다.
