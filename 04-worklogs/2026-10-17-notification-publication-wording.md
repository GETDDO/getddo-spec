# 작업 기록: 최초 공개 알림 문구 동기화

- 작성일: 2026-10-17
- 작성: Codex
- 관련 이슈 / PR: 알림·결과 공개 담당 문서 동기화, BE GD-199 PR #108 연동 경계
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

사용자가 요청한 알림의 ‘마감 5분 후 자동 공개’ 문구 정정을 최신 수동 발표 요구사항에 맞춰 원격에 반영한다. 전날 별도 작업 폴더에 준비한 문구를 최신 명세 기준으로 재확인했다.

## 한 일

- 알림 도메인과 API 문서를 관리자의 발표 요청에 따른 실제 최초 공개로 정렬했다.
- 시간 경과·추첨 완료·명단 검토만으로 알림을 생성하지 않고 같은 공개 건 재시도로 중복 생성하지 않음을 명시했다.
- 기존 담당자 동기화 후속 항목에 문구 반영 사실을 연결했다.
- 수신 대상·API 경로·DTO·오류·DB 모델·알림 구현 코드는 변경하지 않았다.

## 확인된 내용

- [결과 발표 요구사항](../00-requirements/functional-requirements.md#10-결과-발표)과 [추첨 규칙](../02-domain/drawing.md#결과-발표)은 관리자 발표 요청과 실제 공개를 기준으로 한다.
- 5분은 자동 추첨 기준이며 자동 최초 공개·카운트다운의 근거가 아니다.
- 문서 diff와 상대 링크를 확인했다. 문서만 수정하므로 테스트·빌드는 실행하지 않았다.
- 실제 배포·DB 데이터·FE 연결은 이번 작업에서 확인하지 않았다.

## 미결정·차단 사항

- 이번 문구 정정의 신규 미결정 사항은 없다. 기존 공개·재시도 정책을 다시 결정하지 않는다.

## 반영 결과

- 변경한 명세: 알림 도메인, 알림 API, 담당자 동기화 항목.
- 관련 ADR: [ADR-022](../03-decisions/022-manual-initial-publication.md). 제안 상태를 임의로 채택으로 변경하지 않았다.
- 관련 PR: spec은 main 직접 반영 방식이다. BE 구현·병합 상태는 별도다.
