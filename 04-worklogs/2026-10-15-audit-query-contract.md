# 2026-10-15 관리자 감사 조회 계약

- 상태: 검토 대기 · Codex 초안 · 담당자 확인 전
- 목적: C의 AU01/AU02 읽기 계약과 변경 전후 데이터 공개 범위를 기록한다.

## 확인과 변경

- 기존 spec 초안, BE의 공통 감사 저장 기반·실제 호출 6파일, 기존 FE의 목록/상세·검색·코드를 읽었다. 준비한 바탕화면 확인안에 응답·검색·오류·공개 데이터 선택과 담당 경계를 정리했다.
- 사용자는 상세안 채택, 확인된 변경 필드 공개, spec main 게시·Jira 작업 생성·구현을 명시적으로 확인했다.
- [감사 API](../05-api/audit.md)에 목록/상세·권한·페이지·UTC 기간·오류와 업무별 필드 선택을 반영했다. 원문 JSON 전체 응답을 허용하지 않으며 저장 원본은 보존한다.
- Jira 중복 검색은 전체 페이지를 확인했다. GD-55는 공통 기록 기반, GD-101은 FE 화면이며 전용 AU01/AU02 BE 작업은 검색 결과에 없었다. 새 작업은 아직 생성 전이다.
- 최신 원격 2753b71의 변경은 응모권 API만으로 감사·사용자 계약은 바뀌지 않았다. 원격 변경을 보존해 게시한다.

## 다음 작업

- GD-62 아래 읽기 작업을 만들고 구현·검증한다. 업무 기록·인증·기존 DB를 선행 변경하지 않는다.
- 활성 관리자·검색·UTC 경계·페이지·필드 제한·원본 무변경을 검증하고 전체 test/build와 dev PR·CI·CodeRabbit을 확인한다.
- FE 접두사와 과거 필터 코드는 담당자 연동으로 구분한다. 실제 브라우저·배포는 아직 검증하지 않았다.
- 공통 감사 트랜잭션에서 롤백된 실패 시도는 이 API의 전체 실패 이력이라고 표현하지 않는다.
