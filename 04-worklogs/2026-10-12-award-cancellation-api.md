## 목적·한 일

CodeRabbit 리뷰에서 확인한 승인 계약과 공용 API 초안의 차이를 정리했다. 기존 대화에서 승인받은 AD05 입력·권한·상태, 미확정 재추첨 중 새 취소 거절과 AD09의 GD-87 실행 응답 재사용을 [추첨 API](../05-api/drawing.md)에 명시했다.

## 확인된 내용

- 변경 전 AD09는 메타데이터 전용 DrawRun 초안이었다. 사용자가 확정 결과 재반환을 위해 DrawExecutionResponse 재사용을 승인했다. runId/status/confirmation과 저장 결과를 사용하는 응답을 반영했다.
- AD05와 AD09는 기존 취소에 연결된 같은 실행을 사용한다. 다른 API DTO 전체나 공개 정책은 변경하지 않았다.
- 변경 전 원격 main·작업 트리 상태가 정상임을 확인했다. 문서와 코드의 실증 결과는 구분한다.

## 미결정·다음 할 일

- 멱등 키의 당첨 결과별/전역 범위와 CANCEL-001~CANCEL-004 오류 문자열 사전은 별도 판단 대상이다. 기존 구현이 해당 정책 승인의 근거가 되지는 않는다.
- 프론트엔드·담당자의 문서 검토와 상세 오류 계약 확인이 남아 있다. 백엔드 검증 결과는 기능 PR 및 별도 백엔드 워크로그를 따른다.
