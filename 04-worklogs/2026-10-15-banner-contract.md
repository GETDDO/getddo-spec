# 배너 계약 정리

- 상태: 검토 대기 · Codex 작성 · 담당자 확인 전
- 목적: 사용자 선택과 기존 DB/API/FE 차이를 확인하고 배너의 공용 계약을 준비한다.

## 확인한 내용

배너의 이벤트 ID 연결·1~5·감사 추적·삭제/취소 사용자 숨김과 관리자 보존·이미지 저장소/공개 주소 분리·삽입 시 밀기와 삭제 시 당김을 사용자에게 각각 선택받았다. 기존 V006은 event_url만 있고 순서1~5 CHECK/UNIQUE가 있다. FE874a64e8 목은0기반 순서·이벤트 삭제 시 배너 자동 삭제가 남아 있다.

## 준비한 내용

[배너 규칙](../02-domain/banner.md), [API 계약](../05-api/banner.md), [ADR-023](../03-decisions/023-banner-event-order-image-url.md)에 사용자 선택과 채택한 상세 계약을 반영했다. 사용자가 상세안 채택·spec main 직접 게시·중복 확인 후 GD-62 하위 Jira 생성과 BE 구현을 승인했다. 이 커밋에 공용 계약8파일을 반영한다. 기존 DB·이미지 환경은 아직 확인하지 않았다.

## 다음 작업

중복 확인 후 Jira 작업을 생성하고 BE를 구현한다. Jira 생성·BE 테스트는 이 명세 커밋 시점에 아직 실행하지 않았다. 기존 운영 행·실제 이미지 기반·FE 연결과 MySQL 원자성 검증은 미확인이다. 이를 구현 완료로 표시하지 않는다. 백엔드 검증·저장 방식은 BE 문서에 남긴다.
