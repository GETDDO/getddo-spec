## 한 일

- 최신 원격 main c0ad92a와 관련 두 API 문서를 대조했다. 두 파일은 기존 로컬과 원격 내용이 동일해 사용자 변경 없이 해당 파일만 수정했다. 로컬 main의 다른 미반영 원격 변경·.idea는 보존했고 pull·reset하지 않았다.
- 사용자는 “관리자도 게임 가능, 비활성 계정은 차단” 선택지를 확인했다. 색깔 G03의 활성 USER/ADMIN 허용과 비활성 403 거절을 반영했다.
- 공통 사용자·인증·다른 관리자 API를 변경하지 않는다. GD-159 공개 오류 계약을 이번 선택으로 확정하지 않는다.
- GD-156의 시작 오류 코드와 공통 500 처리, FE 실패 시 시작 금지를 시작 계약에 정리했다.
