# 작업 기록: 알림 자동 재시도와 관리자 실패 복구 정책 명확화

- 작성일: 2026-10-12
- 관련 이슈 / PR: GD-72 / PR 없음
- 상태: 검토 대기
- 영향 범위: 공통 / 프론트엔드 / 백엔드

## 목적

이벤트 시작 10분 전 자동 1회 안내와 실패 처리 복구를 구분하고, 사용자가 확인한 자동 재시도 횟수와 관리자 복구 순서를 기준 문서에 반영한다.

## 한 일

- 최신 원격 main의 알림 도메인·API 문서와 로컬 내용이 일치하는지 확인하고 관련 문서만 변경했다.
- 자동 재시도와 관리자 복구의 기준을 알림 도메인 문서에 작성했다.
- 최초 정리에서 관리자 API는 검토 대기로 유지했고, 이후 사용자 승인으로 AN01~AN05 세부 계약을 확정했다.
- 기존 .idea 미추적 파일을 보존했다. 사용자의 커밋·푸시 요청을 받고, 관련 문서와 원격 변경이 겹치지 않는지 확인한 뒤 원격 main을 fast-forward로 반영했다.

## 확인된 내용

- 사용자가 최초 처리 후 실패 시 시스템이 최대 3회 재시도하고 이후 관리자 복구로 전환하는 방향을 확인했다.
- 기준 문서: [알림 도메인](../02-domain/notification.md#실패-재시도-및-관리자-복구).
- 정상 시작 알림 1회와 실패 복구는 구분하며 사용자 알림 중복·읽음 상태 변경을 방지한다.

## 다음 할 일

- [ ] GD-72 관리자 조회·복구 API 계약 확인 및 구현.
- [ ] 현재 구현의 오류 분류·자동 재시도·최종 실패 판정을 명확화된 정책과 대조한다. 비일시적 오류는 즉시 최종 실패로 기록하는 방향을 사용자에게 추가 확인했다.

## 미결정·차단 사항

- 최초 정리 당시 관리자 API와 복구 이후 재시도 구간은 미확정이었다. 이후 사용자가 추천안 전체를 승인하여 관리자 AN01~AN05, 일시적 오류만 자동 재시도하는 예외, 시점이 지난 시작 안내 생성 복구 제한과 새 복구 구간을 확정했다.
- 관리자 API 상태는 [알림 API](../05-api/notification.md)를 따른다.
