# 출석 도메인 규칙

## 기본 출석

- 출석은 이벤트별이 아닌 사용자 단위로 관리한다.
- 일일 출석 보상의 초기 설정은 브론즈 응모권 1장이다. 설정된 일일 수량을 지급한다.
- 사용자별 출석 가능 횟수는 매일 00:00 KST(Asia/Seoul)에 초기화한다. 서버에서는 해당 시각을 UTC로 변환해 처리한다.
- 같은 사용자의 같은 출석 기준일에는 출석을 한 번만 인정하고 보상도 한 번만 지급한다.
- 버튼 연타·새로고침·동시 요청·날짜 변경 경계에서도 같은 출석은 한 번만 반영한다.
- 별도 출석 동작으로 출석을 인정한다.

## 연속 출석

- 연속 출석은 매월 초기화되며 같은 달 안에서 달성 여부를 판정한다.
- 연속 출석 일수는 매월 1일 00:00 KST에 0으로 초기화한다.
- 출석하지 않은 날이 있으면 연속 출석 일수는 0으로 돌아간다.
- 연속 출석 단계의 초기 설정은 7일·14일·28일이며 보상은 각각 1장·3장·7장이다. 해당 월에 적용되는 단계와 보상 설정으로 판정한다.
- 같은 달에 같은 단계의 보상은 한 번만 지급한다. 연속이 끊긴 뒤 다시 같은 일수에 도달해도 추가로 지급하지 않는다.
- 상위 단계 달성은 하위 단계 보상을 대체하지 않는다. 세 단계를 모두 달성하면 각각 지급하며, 초기 설정에서 사용자당 한 달 최대 보상은 11장이다. 정책 변경 후 최대치는 해당 월의 단계별 보상 합계다.
- 월 단위로 초기화하므로 28일을 초과하는 단계는 두지 않는다.

## 보상 지급과 중복 방지

- 기본 출석과 연속 출석 단계 보상은 브론즈(`BRONZE`) 응모권으로 고정 지급한다. 게임·미션의 무작위 등급 추첨은 출석에 적용하지 않는다. 브론즈의 장당 가중치는 가중치 적용 이벤트에서 1이며, 지급 장수는 기존 출석 보상 수량 정책을 따른다. 지급 이력과 잔액 규칙은 [응모권 도메인 규칙](ticket.md)을 따른다.
- 같은 보상 건의 지급 요청이 반복돼도 한 번만 반영한다.
- 출석 기록과 응모권 지급 결과의 일치를 보장한다.

## 정책 변경

- 관리자는 기본 출석 보상 수량, 연속 출석 단계 일수와 단계별 보상 수량을 수정할 수 있다. 보상 수량은 1장 이상이어야 한다.
- 단계 일수는 1~28일 범위에서 중복 없이 오름차순으로 설정한다.
- 기본 출석 변경은 다음 일일 기준일(00:00 KST)부터, 연속 출석 변경은 다음 KST 기준월부터 적용한다.
- 기존 달성·지급 기록을 소급 변경하지 않는다. 같은 월의 단계 판정에는 해당 월에 적용된 정책을 유지한다.
- 일일 출석 1회, 매월 연속 일수 초기화, 누락 시 연속 초기화, 단계별 월 1회 지급 규칙은 유지한다.

## 2026-10-07 등급 확정

- 변경 전: 기본·연속 출석 보상의 응모권 등급은 미결정이었다.
- 변경 후: 기본·연속 출석 보상 모두 브론즈 응모권으로 지급한다.
- 지급 수량, 단계 일수, 중복 방지와 적용 시점 규칙은 이번 등급 확정으로 변경하지 않는다. 기존 무등급 지급분의 전환·적용 시점은 [미결정 사항](../00-requirements/pending-decisions.md#등급-응모권)을 따른다.
- 결정 기록: [ADR-016](../03-decisions/016-attendance-bronze-tickets.md).
