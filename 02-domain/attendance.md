# 출석 도메인 규칙

## 기본 출석

- 출석은 이벤트별이 아닌 사용자 단위로 관리한다.
- 일일 출석 시 응모권 1장을 지급한다.
- 사용자별 출석 가능 횟수는 매일 00:00 UTC에 초기화한다. 화면 기준으로는 09:00 KST다.
- 같은 사용자의 같은 출석 기준일에는 출석을 한 번만 인정하고 보상도 한 번만 지급한다.
- 버튼 연타·새로고침·동시 요청·날짜 변경 경계에서도 같은 출석은 한 번만 반영한다.
- 별도 출석 동작으로 출석을 인정한다.

## 연속 출석

- 연속 출석은 매월 초기화되며 같은 달 안에서 달성 여부를 판정한다.
- 연속 출석 일수는 매월 1일 0으로 초기화한다.
- 출석하지 않은 날이 있으면 연속 출석 일수는 0으로 돌아간다.
- 연속 출석 일수가 7일·14일·28일에 도달하면 각 단계의 보상 응모권을 지급한다. 단계별 보상은 각각 1장·3장·7장이다.
- 같은 달에 같은 단계의 보상은 한 번만 지급한다. 연속이 끊긴 뒤 다시 같은 일수에 도달해도 추가로 지급하지 않는다.
- 상위 단계 달성은 하위 단계 보상을 대체하지 않는다. 세 단계를 모두 달성하면 각각 지급하며, 사용자당 한 달에 받을 수 있는 연속 출석 보상은 최대 11장이다.
- 월 단위로 초기화하므로 28일을 초과하는 단계는 두지 않는다.

## 보상 지급과 중복 방지

- 출석과 연속 출석 보상은 응모권으로 지급한다. 지급 이력과 잔액 규칙은 [응모권 도메인 규칙](ticket.md)을 따른다.
- 같은 보상 건의 지급 요청이 반복돼도 한 번만 반영한다.
- 출석 기록과 응모권 지급 결과의 일치를 보장한다.

미확정된 연속 출석 관련 정책은 [미결정 사항](../00-requirements/pending-decisions.md#출석)에 기록한다.
