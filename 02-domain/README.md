# 도메인 규칙

프론트엔드와 백엔드가 동일하게 이해하고 구현해야 하는 용어와 비즈니스 규칙을 관리합니다.

## 관리 범위

- 공통 용어와 표현
- 이벤트 상태와 변경 조건
- 응모권의 지급, 차감, 만료 및 반환
- 출석과 미션의 달성 판정, 보상 지급 조건
- 게임 결과 판정과 보상 지급 조건
- 이벤트 응모 조건과 제한
- 추첨, 재추첨 및 결과 발표
- 사용자 알림 정책
