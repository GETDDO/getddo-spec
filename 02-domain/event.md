# 이벤트 도메인 규칙

이벤트·경품의 동시 등록과 등수별 경품 구성은 [이벤트 등록 요구사항](../00-requirements/functional-requirements.md#이벤트-등록-및-관리)을 따른다.

## 수정 및 삭제 제한

- 시작 전이며 진행 예정 상태인 이벤트는 아래 제한 안에서 설정을 수정할 수 있다.
- 취소 상태에서는 시작 시각 전이라도 제목·설명·이미지·경품·응모 조건을 포함한 이벤트 정보를 수정할 수 없다. 취소는 정보 수정과 구분한다.
- 등록된 이벤트의 응모 시작 시각은 현재 설정된 시작 시각보다 앞당길 수 없다. 시작 전이며 진행 예정 상태에서는 시작 시각을 늦출 수 있다.
- 진행 중에는 제목·설명·이미지를 포함한 이벤트 정보를 수정할 수 없다.
- 진행 중 경품·응모권 차감 수량·당첨 인원·마감 시각 등 응모 조건을 변경할 수 없다.
- 마감 후에는 이벤트 정보를 수정할 수 없다.
- 시작 전이며 응모 이력이 없는 이벤트만 삭제할 수 있다.
- 이벤트 삭제 시 해당 이벤트에 연결된 배너도 함께 삭제한다. 연결된 배너가 있다는 이유로 이벤트 삭제를 제한하지 않는다.
- 이벤트 취소는 정보 수정과 구분하는 최종 종료다. 이벤트 일시 중단·재개와 중단 시간 설정은 제공하지 않는다.
- 이벤트 취소 시 해당 이벤트의 응모에 차감한 응모권을 반환한다.
- 취소 처리와 대상 응모권 반환을 함께 완료한다. 취소 완료 후 별도 배치로 반환하지 않는다. 실패 시 둘 다 완료된 것으로 처리하지 않고 재시도에도 중복 반환하지 않는다.
- 취소와 응모가 동시에 처리되면 서버에서 먼저 확정된 처리 순서를 적용한다. 응모가 먼저 확정되면 취소 시 차감한 응모권을 반환하고, 취소가 먼저 확정되면 이후 응모를 거절한다.

## 상태 관리

- 진행 예정, 진행 중, 마감, 추첨 결과 확정·발표 대기, 결과 발표 완료, 취소, 재추첨 상태를 구분한다.
- 시스템은 이벤트 상태를 관리하며, 관리자는 허용된 상태 변경을 수행한다.
- 최초 결과 발표는 응모 마감 시각 + 5분에 시스템이 자동으로 시작하며 별도 관리자 승인을 요구하지 않는다. 마감 후 검토·카운트다운과 발표 기준은 [추첨 규칙](drawing.md#결과-발표)을 따른다.
- 최초 발표 전 취소된 이벤트는 예약된 자동 발표를 진행하지 않는다.
- 관리자는 이벤트 상태와 관계없이 언제든지 이벤트를 취소할 수 있다. 추첨 결과 확정·발표 대기, 결과 발표 완료 및 종료 상태도 포함한다.
- '응모자 없음'과 '추첨 대상자 없음' 종료 상태를 구분한다.

재추첨 상태의 진입·종료는 [추첨 규칙](drawing.md#재추첨), 반환 응모권 유효기간은 [응모권 규칙](ticket.md#사용-범위유효기간)을 따른다.
