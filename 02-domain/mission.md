# 미션 도메인 규칙

## 일회성 미션

- 사용자당 이벤트 기간 중 1회만 달성할 수 있는 미션을 제공한다.
- 미션 내용, 완료 조건, 보상 응모권 수를 관리한다.
- 동일 미션 달성 건의 중복 처리·보상 지급을 방지한다.
- 미션 완료는 서버가 판정하며, 관리자 승인이나 별도 배치 지급을 기다리지 않는다.
- 설문 참여와 브랜드 퀴즈를 일회성 미션으로 제공한다.
- 출석과 게임은 미션으로 관리하지 않는다. 각각 [출석 도메인 규칙](attendance.md)과 [게임 도메인 규칙](game.md)을 따른다.

## 설문 미션

- 설문은 서비스 내부에서 제공하고 응답을 받는다.
- 모든 필수 문항에 답변하고 최종 제출한 경우에만 완료로 인정한다.
- 서버가 최종 제출 답변의 필수 문항 충족 여부를 확인한 즉시 설정된 보상 응모권을 지급한다.
- 필수 문항 답변 누락, 단순 방문·입력은 완료로 인정하지 않으며 보상을 지급하지 않는다.
- 같은 사용자의 동일 설문 미션 달성·보상은 재제출·재시도·동시 요청에도 한 번만 반영한다.

## 브랜드 퀴즈 미션

- 퀴즈는 서비스 내부에서 제공하고 답변을 받는다.
- 제출한 답이 정답인 경우에만 완료로 인정하고 보상 응모권을 지급한다. 참여만으로는 지급하지 않는다.
- 오답이면 완료로 기록하지 않으며, 사용자는 다시 답변할 수 있다.
- 재도전으로 정답을 맞혀도 같은 미션의 보상은 한 번만 지급한다.
- 문항과 정답은 관리자가 관리하며, 정답 정보는 사용자에게 제공하는 응답에 포함하지 않는다.

## 보상 지급과 중복 방지

- 미션 보상은 응모권으로 지급한다. 지급 이력과 잔액 규칙은 [응모권 도메인 규칙](ticket.md)을 따른다.
- 같은 보상 건의 지급 요청이 반복돼도 한 번만 반영한다.
- 미션 수행 기록과 응모권 지급 결과의 일치를 보장한다.

미확정된 미션 소속 범위, 미션별 보상 수량 및 퀴즈 재도전 제한 정책은 [미결정 사항](../00-requirements/pending-decisions.md#일회성-미션)에 기록한다.
