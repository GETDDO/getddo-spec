# 미션 도메인 규칙

## 서비스 공통 미션

- 미션은 특정 이벤트에 속하지 않는 서비스 공통 퀴즈·설문이다.
- 관리자가 매번 새 미션과 문항을 수동 등록한다. 자동 반복, 반복 주기 및 같은 미션의 재달성은 제공하지 않는다.
- 사용자당 각 미션을 1회만 달성하고 보상도 1회만 받는다. 새로 등록된 다른 미션은 별도로 달성할 수 있다.
- 미션별 내용, 완료 조건, 보상 응모권 수와 이벤트에 독립적인 운영 시작·종료 시각을 관리한다.
- 운영 중인 미션의 조건·문항·보상은 유지하며 변경은 신규 등록 미션에 적용한다.
- 출석과 게임은 미션으로 관리하지 않는다. 각각 [출석 규칙](attendance.md)과 [게임 규칙](game.md)을 따른다.

## 제출 인정 시간

- 운영 시작 시각 이상·종료 시각 미만에 서버가 받은 제출을 인정한다. 클라이언트가 보낸 시각을 기준으로 삼지 않는다.
- 기간 내 도착한 제출은 검증이 종료 후 끝나더라도 완료 조건을 충족하면 달성·보상을 반영한다.
- 정확히 종료 시각부터 도착한 제출은 인정하지 않는다.
- 미션 제출의 도착 시각 기준은 DB 확정을 기준으로 하는 이벤트 응모 접수와 구분한다.

## 설문 미션

- 서비스 내부에서 응답을 받고, 모든 필수 문항에 답변해 최종 제출한 경우에만 완료로 인정한다.
- 서버가 필수 문항 충족을 확인하면 관리자 승인이나 배치를 기다리지 않고 설정된 보상 응모권을 지급한다.
- 필수 문항 누락, 단순 방문·입력에는 달성·보상을 반영하지 않는다.
- 동일 사용자의 동일 미션 재제출·동시 요청에도 달성·보상은 한 번만 반영하고 완료된 응답을 덮어쓰지 않는다.

## 브랜드 퀴즈 미션

- 서비스 내부에서 답변을 받고 서버가 정답임을 확인한 경우에만 완료·보상 지급으로 처리한다.
- 오답은 완료·보상으로 기록하지 않으며 운영 기간 안에서 횟수 제한 없이 재도전할 수 있다.
- 정답으로 완료한 미션을 다시 풀어도 추가 달성·보상을 지급하지 않는다.
- 문항과 정답은 관리자가 등록하며, 정답 정보는 사용자에게 제공하는 응답에 포함하지 않는다.
- 짧은 시간의 과도한 제출에는 [요청 빈도 제한](entry.md#요청-빈도-제한)을 적용한다. 재도전 총횟수 제한과는 구분한다.

## 보상 지급과 중복 방지

- 미션 보상은 응모권으로 지급하며 [응모권 규칙](ticket.md)을 따른다.
- 사용자·미션 단위로 달성과 지급의 중복을 방지한다.
- 미션 수행 기록과 응모권 지급 결과의 일치를 보장한다.
