# 응모 도메인 규칙

## 응모 처리

- 사용자의 멤버십 등급이 이벤트의 최소 허용 등급 이상인지 검증한다. 등급 순서는 우수 < VIP < VVIP이며, 시작 알림 대상에도 같은 최소 등급 기준을 적용한다.
- 응모권 미사용 이벤트는 경품을 선택하지 않고 이벤트에 응모하며 응모권을 차감하지 않는다.
- 응모권 사용 이벤트는 모집 시간 내에 응모권을 차감해 응모한다.
- 일반 가중치 적용 이벤트는 사용자당 해당 이벤트에서 추가 응모를 포함해 응모권을 누적 최대 5장까지 사용할 수 있다. 1회 요청당 제한이 아니라 이벤트별 사용자 누적 사용 상한이다. 월말 소진용 이벤트의 상한 없음 예외는 [응모권 규칙](ticket.md)을 따른다.
- 가중치 미적용 이벤트는 응모권 1장을 차감해 응모한다.
- 응모권의 유효기간과 보유 수량을 검증한다.
- 같은 요청의 재시도와 새로운 응모를 구분해 중복 반영을 방지한다.
- 응모권 차감·차감 이력·응모 기록은 함께 성공하거나 함께 실패하도록 처리한다.
- 응모권 미사용 이벤트도 같은 요청의 재시도로 응모 기록이 중복 생성되지 않도록 한다.
- 접수 완료 시점은 응모 기록·응모권 차감·차감 이력이 하나의 DB 트랜잭션으로 확정된 시점이다. 응모권 미사용 이벤트는 응모 기록 확정 시점이다.
- 서버 검증 통과나 성공 응답 전달을 접수 완료로 보지 않는다. DB 확정 후 통신이 끊겨도 응모는 유지하며 재요청에는 기존 결과를 반환한다.
- 응모권 만료 전 차감·접수까지 완료한 응모만 인정하며 월이 바뀌거나 추첨이 늦어져도 완료된 응모는 유지한다.
- 중단·취소와 동시 처리하는 순서는 [이벤트 규칙](event.md)을 따른다.

## 응모 횟수 및 취소

- 응모권 미사용 이벤트는 사용자당 최대 1회 응모할 수 있다.
- 가중치 미적용 이벤트는 사용자당 해당 이벤트에 1회만 응모하며 응모권 1장을 차감한다.
- 일반 가중치 적용 이벤트는 사용자별 누적 5장 이내에서 추가 응모를 허용한다. 이미 3장을 사용했다면 최대 2장만 추가할 수 있고, 5장을 사용했다면 더 응모할 수 없다. 월말 소진용 이벤트는 수량 상한 없이 추가 응모할 수 있다.
- 프론트엔드는 누적 사용량과 남은 사용 가능 수량을 표시하고, 서버는 동시 요청에도 누적 상한과 유효 보유량을 초과하지 않도록 검증한다.
- 사용자의 응모 취소는 제공하지 않는다.
- 이벤트 중단·취소에 따른 응모권 반환은 이벤트 도메인 정책을 적용한다.

## 마감 판정

- 서버에서 마감 전에 접수 완료된 응모만 인정한다.
- 정확히 마감 시각부터는 응모할 수 없다.
- 마감 전에 접수 완료된 응모는 응답이 마감 후 도착해도 유효하다.
- 응모권 사용 이벤트는 응모 접수 완료 시점을 기준으로 판단하며, 추첨 시점의 접속 유지는 요구하지 않는다.

## 어뷰징 탐지 및 관리자 검토

- 비정상 반복 응모를 탐지하고 사용자·이벤트·탐지 사유·발생 시각·관련 요청을 기록한다.
- 탐지 사실만으로 자동 제외하지 않는다.
- 이벤트 응모 검토와 응모권 지급 검토를 구분한다. 부정 지급 검토는 이벤트 응모 전에도 가능하다.
- 관리자는 참여 허용 또는 해당 이벤트의 추첨 대상 제외를 결정한다.
- '참여 허용'은 관리자 검토 결과이며, 응모 접수 완료와 구분한다.
- 검토 상태, 검토자, 검토 시각, 사유를 기록한다.
- 제외 확정 전에 관리자가 사유를 확인·기록한다.
- 제외된 본인에게만 제외 사실과 사유를 안내하고 일반 낙첨과 구분한다.
- 구체적인 탐지 수치 및 다른 사용자 정보는 공개하지 않는다.
- 마감 검토는 마감 전 응모와 관련된 탐지 건을 대상으로 한다.
- 마감 후 단순 접속·재시도로 추첨 대기를 늘리지 않는다.
- 별도 이의 제기는 이번 버전에서 제외한다.

## 탐지 범위와 담당자 운영

- 사용자별 요청 빈도와 비정상 요청 반복을 함께 탐지한다. 허용 횟수 초과·마감 후 요청 등의 사유를 기록한다.
- 정상 추가 응모와 통신 재시도를 부정으로 단정하지 않는다. 동일 요청 재전송은 구분해 기록한다.
- 출석·미션·게임의 응모권 지급 단계에도 자동화 의심·비정상 지급 시도 탐지를 적용한다.
- 유효성 검증을 통과한 게임이라도 부정 의심 건은 관리자 검토 후 조치한다. 의심만으로 점수·보상을 보류·취소하지 않는다.
- 관리자가 부정을 확인하면 관련 점수 무효화·부정 보상 회수·응모 제외 정책을 적용한다. 당첨자·낙첨자의 사후 처리는 [추첨 규칙](drawing.md)을 따른다.
- 탐지 적용은 확정 정책이다. 세부 조건·시간·횟수는 담당자가 관리·수정하며 정책 미결정으로 분류하지 않는다. 응모·지급 단계 담당: 석종수, 게임 검증 담당: 윤태형.

## 요청 빈도 제한

- 이벤트 응모, 출석, 미션 제출, 게임 결과 제출에 사용자별 요청 빈도 제한을 적용한다.
- 제한 초과 시 일시적으로 요청을 제한하고 잠시 후 재시도하도록 안내한다. 제한 초과만으로 부정 사용자로 확정하지 않는다.
- 기능별 수치는 담당자가 관리·수정한다. 퀴즈 재도전 총횟수와 게임 플레이 총횟수는 무제한으로 유지한다.
- CAPTCHA 등 추가 인증은 이번 결정으로 도입하지 않는다.
