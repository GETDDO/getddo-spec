# 용어

| 용어 | 정의 및 적용 기준 |
| --- | --- |
| 경품 | 이벤트 당첨 물품. 상품과 혼용하지 않는다. |
| 이벤트 응모 | 이벤트에 신청하는 행위. 출석·게임·설문 행위까지 응모로 바꾸지는 않는다. |
| 응모자 | 이벤트 신청 사용자. 참여자와 혼용하지 않는다. |
| 응모 기간 | 이벤트 신청 가능 기간. |
| 응모권 미사용 이벤트 | 응모권을 차감하지 않는 이벤트. 무료 이벤트라는 표현은 결제와 혼동될 수 있어 사용하지 않는다. |
| 응모권 사용 이벤트 | 응모권을 차감해 응모하는 이벤트. |
| 응모권 차감 | 응모에 따라 응모권 잔액을 줄이는 처리. 응모 행위와 구분한다. |
| 총 응모에 차감한 응모권 수 | 모든 응모에 차감된 응모권 수. 반환 등과 혼동하지 않도록 행위를 명시한다. |
| 미션 | 관리자가 매번 수동 등록하는 서비스 공통 퀴즈·설문. 사용자당 미션별 달성·보상은 1회다. |
| 미션 달성 건 | 사용자·미션별 완료 조건 충족 기록. 동일 미션의 요청 재시도는 새 달성이 아니다. |
| 퀴즈 재도전 | 오답 후 다시 답변하는 행위. 횟수 제한이 없으며 오답에는 보상을 지급하지 않는다. |
| 지급 | 출석·미션·게임 등에 따른 보상 부여. |
| 응모권 등급 | 게임·미션 보상으로 무작위 지급하는 브론즈·실버·골드 구분. 사용자 멤버십 등급과 다른 개념이다. |
| 실제 응모권 장수 | 보유·지급·차감한 응모권의 개수. 골드·실버·브론즈 각각 1장은 장수 1로 계산한다. |
| 등급별 추첨 가중치 | 가중치 적용 이벤트에서 차감한 등급 응모권 1장이 기여하는 값. 상세 값과 획득 확률은 [응모권 규칙](ticket.md#게임미션-보상의-등급-추첨)을 따른다. |
| 차감 이력 | 응모권 잔액 감소 이력. |
| 응모권 만료 | 월별 유효기간 종료에 따른 응모권 처리. 소멸은 처리 의미를 설명할 때만 사용한다. |
| 접수 완료된 응모 | 기술적으로 접수가 완료된 응모. 관리자의 참여 허용 판단과 구분한다. |
| 응모 접수 완료 시점 | 응모 기록과 필요한 응모권 차감·이력이 하나의 DB 트랜잭션으로 확정된 시점. 미사용 이벤트는 응모 기록 확정 시점이다. |
| 결과 발표 | 확정된 추첨 결과를 공개하는 행위. |
| 어뷰징 탐지 | 비정상 반복 응모·보상 조작 등을 탐지하는 행위. |
| 사용자당 | 가상 사용자를 포함해 고정 사용자 ID를 기준으로 적용하는 제한 단위. |
| 취소 | 이벤트를 최종 종료하는 관리자 처리. 이후 응모하거나 운영을 재개할 수 없다. |

응모는 이벤트에 신청하는 행위이며, 응모권 차감은 응모에 따라 응모권 잔액을 줄이는 처리다.

이벤트를 일시 중단하거나 재개하는 기능은 제공하지 않는다.
