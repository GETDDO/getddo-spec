# 게임 도메인 규칙

## 게임 제공

- 여러 종류의 게임을 제공한다.
- 게임은 순환 방식이 아닌 전체 게임을 한 번에 공개한다.
- 게임은 횟수 제한 없이 플레이할 수 있다.

## 글자색깔 맞추기 규칙

2026-10-12 게임 담당자 확인으로 현재 프론트의 아래 플레이 규칙을 채택했다.

- 글자의 뜻이 아니라 글자에 칠해진 색을 고르면 정답이다.
- 정답 1개당 10점을 얻는다.
- 목숨은 3개로 시작한다. 오답 또는 제한 시간 초과 시 목숨 1개를 잃으며, 목숨을 모두 잃으면 한 판이 종료된다.
- 문제별 제한 시간은 3초부터 시작하고, 누적 정답 1개마다 0.08초씩 줄어 최소 1.2초를 유지한다. 다음 문제의 제한 시간은 `max(1200, 3000 - 누적 정답 수 × 80)`밀리초다.
- 오답·시간 초과로 목숨을 잃는 정상적인 게임 진행과 서버의 무효 플레이 판정은 구분한다. 오답을 냈다는 이유만으로 부정 플레이로 판단하지 않는다.

### 색깔 게임의 시간·종료·보상일

2026-10-12 사용자의 명세 우선·추천안 적용 지시에 따라 아래 방식을 채택했다.

- 일시정지와 탭 이동 시 자동 정지를 유지한다. 일시정지·시작/재개 카운트다운·정답 연출 시간은 문제 풀이 시간에서 제외하며, 재개 시 같은 문제의 남은 시간을 이어간다.
- 풀이 시간이 해당 문제의 제한 시간보다 작은 답변만 인정한다. 제한 시간에 정확히 도달하거나 넘으면 시간 초과로 한 번 처리한다.
- 중간에 나가거나 창을 닫아 자연 종료하지 않은 플레이는 점수·횟수·보상에 반영하지 않는다. 자연 종료 후 제출 실패는 같은 플레이의 결과 재시도로 처리한다.
- 보상일은 서버가 최초 유효 결과를 확정한 완료 시각의 KST 날짜다. 트랜잭션이 롤백되면 확정으로 보지 않으며, 성공 후 재시도는 최초 결과·보상일을 유지한다.
- 문제 생성 기준을 서버가 발급하고 답변 기록을 종료 시 일괄 제출해 서버에서 점수를 계산한다. 클라이언트 입력 기록만으로 실제 사람의 플레이를 증명하지는 못한다. 세부 필드·버전·재시도는 [색깔 게임 연동 계약](../05-api/game-color-word-draft.md)을 따른다.

위 색깔 게임 결정으로 타꼬런을 확정한 것은 아니다. 타꼬런은 아래 2026-10-16 별도 선택을 따른다. 추가 어뷰징 차단 기준은 후속 확인을 유지한다.

## 타꼬런 규칙 — 2026-10-16 사용자 선택

- FE 초안 A안의 서버 재현 방식, TAKKO_RUN·고정120Hz·xorshift32·endTick과 press/release 입력을 채택한다. 400점 최소 보상 기준은 유지한다.
- 원본 점프·속도·거리 점수·장애물 규칙을 버전별로 고정하고 매 판 첫 점프부터 진행한다. 중간 이탈이나 종료 후 추가 기록을 정상 완료로 인정하지 않는다.
- 충돌 또는 활성10분(72,000tick) 도달이 정상 종료다. endTick은0부터 시작하므로 시간 종료 번호는71999다. 정지·탭 이동·카운트다운은 활성시간에서 제외한다.
- 추가 질문으로 선택한10분 종료와 서버 경과시간 대조 후속을 FE 초안에 보완했다. 일괄 기록만으로 사람의 플레이를 증명하지 못하며 새 총시간 차단 임계값은 추가하지 않는다.
- G02/G03 공개 규칙·입력 한도·종료·재시도는 [타꼬런 연동 계약](../05-api/game-takko-run-draft.md)을 따른다. 타이밍·주문은 미확정 상태를 유지한다.

## 결과 판정

- 게임 점수는 서버가 판정한다. 사용자가 제출한 점수를 그대로 인정하지 않는다.
- 서버는 플레이마다 결과를 유효 또는 무효로 판정한다.
- 무효로 판정한 플레이는 점수 기록과 보상 지급에 반영하지 않는다.
- 서버가 발급한 플레이 ID로 동일 플레이를 구분한다. 같은 플레이에 대한 재제출에는 최초로 확정한 결과를 반환하며 새 점수·횟수·보상을 추가하지 않는다.
- 처리 중인 요청에는 처리 중임을 안내한다. 새 플레이와 동일 플레이의 재시도를 구분한다.

## 점수 기록

- 게임별 점수를 기록하며 개인 최고점과 누적 점수를 보관한다.
- 유효로 판정한 플레이만 개인 최고점, 누적 점수 및 플레이 횟수에 반영한다.

## 보상 지급

- 게임 보상은 사용자별로 각 게임에서 하루 1회 등급 응모권 1장을 지급한다. 같은 날 서로 다른 게임의 보상은 각각 받을 수 있다.
- 보상 기준일은 매일 00:00 KST(Asia/Seoul)에 초기화한다.
- 서버가 유효로 판정한 한 판의 점수가 아래 최소 보상 점수 이상이고, 해당 보상 기준일에 그 게임의 보상을 받지 않았을 때 지급한다. 정확히 기준 점수인 경우도 포함한다.

| 게임 | 최소 보상 점수 |
| --- | ---: |
| 타꼬런 | 400점 |
| 글자색깔 맞추기 | 50점 |

- 여러 판의 점수를 합산해 보상 조건을 충족할 수 없다. 기준 도달 중간에 즉시 지급하지 않고 서버가 유효한 완료 결과로 확정한 점수로 판정한다.
- 기준 미만의 정상 플레이는 0점도 유효로 처리해 개인 최고점·누적 점수·플레이 횟수에 반영한다. 보상 청구·응모권 지급은 하지 않고 일일 보상 기회도 사용하지 않는다. 같은 날 새 플레이에서 기준을 충족하면 지급받을 수 있다.
- 동일 플레이 재시도는 최초 결과와 보상 유무를 유지한다. 이후 다른 플레이에서 보상을 받았다고 앞선 저득점 플레이에 보상을 추가하지 않는다.
- 최소 점수를 충족한 뒤에도 점수나 플레이 횟수에 따른 지급 장수 차등은 없다. 지급 수량은 항상 1장이며 등급은 [응모권 등급 추첨 규칙](ticket.md#게임미션-보상의-등급-추첨)에 따라 무작위로 결정한다.
- 같은 게임의 반복 플레이나 보상 정책 변경으로 동일 보상 기준일의 지급 제한이 초기화되지 않는다.
- 보상 응모권의 지급 이력과 잔액 규칙은 [응모권 도메인 규칙](ticket.md)을 따른다.

## 어뷰징

- 지급 전 서버 검증과 차단 기록은 [응모·어뷰징 규칙](entry.md#응모권-지급-전-검증-및-차단-내역)을 따른다. 차단 적용 대상·판정 기준은 후속 확인하며 기존 무효 플레이 처리와 의심만으로 보류하지 않는 원칙을 임의로 확대·변경하지 않는다.
- 지급 후 발견한 부정의 점수 무효화 유지 여부는 후속 확인한다. 후속 결정 전에는 아래 기존 사후 처리 정책을 유지한다.

- 의심만으로 점수·보상을 보류하거나 취소하지 않는다. 관리자가 부정을 확인한 후 점수 무효화 등 후속 조치를 수행한다. 응모권 회수는 [응모권 규칙](ticket.md#응모권-회수-제외)에 따라 이번 버전에서 제외한다.
- 확실한 규칙 위반으로 서버가 무효 판정한 플레이는 기존대로 즉시 반영에서 제외한다.
- 탐지 및 사용자별 요청 빈도 제한은 [응모·어뷰징 규칙](entry.md#탐지-범위와-담당자-운영)을 따른다. 세부 기준은 담당자가 관리·수정한다.

## 운영과 담당자 후속 작업

- 글자색깔 맞추기는 위 규칙을 따른다. 다른 게임의 제공 종류·규칙은 게임 담당자가 확정 후 공유한다. 타코야끼 만들기는 후보이며 확정 게임이 아니다.
- 서버 판정 원칙을 유지하며 게임별 검증 방식은 전민규 담당자가 설계 후 공유한다.
- 허용된 게임 보상 정책 변경은 다음 일일 기준일부터 적용한다. 기존 점수·지급 이력과 사용자별·게임별 하루 1회 1장 제한은 유지한다.
- 담당자 작업 목록은 [미결정·후속 사항](../00-requirements/pending-decisions.md#게임)을 따른다.
