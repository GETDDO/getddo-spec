# ADR-006: 서비스 공통 미션과 반복 달성

> 후속 결정: [ADR-008](008-finalized-service-policies.md)이 관련 미결정 항목과 일부 정책을 갱신했다. 아래 본문은 당시 결정 기록이며 현재 기준은 ADR-008과 도메인 문서를 따른다.

- 상태: 채택
- 작성자 / 날짜: 사용자 결정에 따라 Codex 정리 / 2026-09-21
- 대체한 ADR: [ADR-005](005-reward-domain-separation.md)의 미션 소속·달성 횟수·재도전 관련 내용만 대체한다.

## 변경 전과 변경 후

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 미션 소속 | 서비스 공통인지 이벤트 소속인지 미정 | 서비스 공통 |
| 달성 횟수 | 사용자당 이벤트 기간 중 1회 | 같은 미션 재달성 허용, 반복 주기는 미션별 설정 |
| 퀴즈 완료 | 정답 제출 시 완료 | 유지 |
| 오답 재도전 | 가능하지만 횟수 제한 미정 | 무제한 허용 |
| 중복 보상 방지 | 사용자·미션 단위 1회 | 동일 달성 건 단위 1회, 새 달성마다 보상 지급 |
| 저장 영역 | 도메인만 분리 | 출석·연속 출석·미션(퀴즈·설문)·게임 테이블 분리 |

## 결정 근거와 범위

사용자가 서비스 공통 소속, 재달성 허용, 테이블 분리 및 퀴즈 무제한 재도전을 명시했다. 기존 일회성 제한은 새 요청과 충돌하므로 대체한다. 출석·연속 출석 보상과 게임의 기존 지급 규칙은 변경하지 않는다.

퀴즈 정답 조건과 동일 달성 건의 중복 지급 방지는 유지한다. 무제한 재도전을 매 요청마다 새 달성·보상으로 처리하는 방식은 채택하지 않는다. 후속 사용자 결정으로 미션별 반복 주기 설정, 재달성마다 보상 지급, 별도 운영 기간 및 관리자 미션·문항 생성을 확정했다. 재달성에는 관리자의 새 문항 등록이 필수이며, 이미 달성한 문항의 재사용으로 추가 보상을 지급하지 않는다. 새 문항 등록은 미션별 반복 주기와 운영 기간 제한을 해제하지 않는다. 반복 주기의 구체적인 시간 기준은 아직 확정하지 않았다.

## 영향

- 프론트엔드: 미션을 이벤트 소속으로 표시하지 않고, 오답 후 다시 답변할 수 있게 한다. 미션별 반복 주기와 운영 기간에 따라 다음 달성 가능 시점을 표시한다.
- 백엔드: 사용자·미션 전체를 1회로 제한하지 않고 개별 달성 건의 중복을 방지한다. 출석·연속 출석·미션·게임 저장 영역을 나눈다. 상세 테이블 설계는 백엔드 문서에서 관리한다.
- 백오피스: 서비스 공통 퀴즈·설문과 보상 수량을 관리한다. 미션·문항 생성, 미션별 반복 주기와 별도 운영 기간 설정을 제공한다. 진행 중 정책 변경 제한은 별도 미결정 사항으로 유지한다.

기준 문서는 [미션 규칙](../02-domain/mission.md), 남은 결정은 [미결정 사항](../02-domain/mission.md)을 따른다.
