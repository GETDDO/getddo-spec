# ADR-013: 추첨 가중치의 선형 환산과 별도 상한·배율 없음

- 상태: 제안
- 작성자 / 날짜: Codex / 2026-09-29
- 검토자: 담당자 검토 대기
- 관련 작업 기록 / PR: [추첨 가중치 정책 확정 설계](../04-worklogs/2026-09-29-drawing-weight-policy.md) / PR 미생성
- 대체한 ADR / 대체된 ADR: [ADR-010](010-five-ticket-entry-limit.md)의 당시 가중치 환산·상한 보류 상태를 해소한다. 응모권 사용 상한 5장 결정은 유지한다.

## 배경

일반 가중치 적용 이벤트에는 사용자당 이벤트별 응모권 누적 사용 상한 5장이 확정되어 있고, 월말 소진용 이벤트에는 사용 수량 상한이 없다. 응모권 수를 추첨 가중치로 환산하는 방식과 가중치 자체의 상한·추가 배율은 미결정이었다. 이벤트별 추첨 기회를 일관되게 정하려면 이 세 항목의 기준이 필요하다.

## 결정과 이유

- 변경 전: 실제 차감 응모권 수의 가중치 환산식, 가중치 자체의 상한, 추가 배율이 보류되어 있었다.
- 변경 후: 가중치 적용 이벤트에서 사용자별 가중치는 해당 이벤트의 접수 완료된 응모에 실제 차감한 응모권의 누적 수와 같다. 추가 응모도 합산하며 거절된 응모와 요청 수량은 반영하지 않는다.
- 일반 이벤트의 가중치는 기존 응모권 누적 사용 상한 5장 때문에 최대 5가 된다. 월말 소진용 이벤트는 유효 보유량 내에서 실제 차감한 장수를 별도 가중치 상한 없이 반영한다. 추가 배율은 적용하지 않는다.
- 응모권 미사용·가중치 미적용 이벤트는 사용자별 가중치 1을 적용한다.

사용자 선택에 따라 응모권 1장당 동일한 추첨 기회를 주는 선형 방식을 사용한다. 월말에 별도 가중치 상한을 두면 상한을 넘겨 사용한 응모권이 추첨 기회를 늘리지 못하므로 두지 않는다. 모든 후보에게 같은 배율을 곱해도 상대적인 선정 확률은 달라지지 않으며, 사용자별 우대 배율은 이번 결정에 포함하지 않는다.

기준 정책은 [추첨 도메인 규칙](../02-domain/drawing.md#가중치-및-중복-당첨)을 따른다.

## 검토한 대안

- 응모권이 늘수록 추가 가중치를 줄이는 점감식과 많이 쓸수록 더 크게 늘리는 제곱식: 각각 장당 기회를 다르게 만들므로 선택하지 않았다.
- 월말 이벤트 가중치를 20 또는 모든 이벤트에서 5로 제한: 상한 초과 사용분이 추첨 기회를 늘리지 못하므로 선택하지 않았다.
- 멤버십·운영 조건별 추가 배율: 사용자별 우대 조건과 다른 담당 영역의 모델·화면 계약이 필요해 이번 정책에 포함하지 않았다.

## 영향과 재검토 조건

- 추첨·재추첨: 접수 완료된 응모에 실제 차감한 응모권 수로 가중치를 산정하고, 재추첨에는 최초 추첨 당시 가중치를 유지한다.
- 프론트엔드·이벤트 설정: 가중치 적용 여부와 이벤트별 응모권 사용 상한을 기존 계약대로 표시한다. 당첨 확률은 표시하지 않는 기존 정책을 유지한다.
- 월말 소진용 이벤트에 매우 많은 응모권이 집중되는 운영 결과가 확인되면 별도 가중치 상한 도입을 재검토한다. 상한을 도입할 때에는 사용자가 얻는 추가 기회와 응모권 소비 정책을 함께 변경해야 한다.
- 이 결정은 사용자별 추첨 기회에 적용하는 공용 정책을 정한다.

## 2026-10-06 후속 결정

게임·미션의 등급 응모권 지급과 등급별 가중치 도입은 [ADR-014](014-random-ticket-grades.md)에 기록한다. 현재 도메인 규칙의 등급별 가중치 합산이 이 문서의 종전 동일 장당 가중치 설명을 대체한다. 이 문서는 변경 전 결정을 보존하며, 실제 장수 기준 사용 상한과 별도 추가 가중치 상한·배율 없음은 유지한다.
