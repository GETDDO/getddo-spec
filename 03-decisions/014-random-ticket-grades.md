# ADR-014: 게임·미션 보상의 무작위 응모권 등급과 등급별 가중치

- 상태: 제안
- 작성자 / 날짜: Codex / 2026-10-06
- 검토자: 담당자 검토 대기
- 관련 작업 기록 / PR: [등급 응모권 정책 반영](../04-worklogs/2026-10-06-random-ticket-grades.md) / PR 미생성
- 대체한 ADR / 대체된 ADR: [ADR-013](013-linear-drawing-weight.md)의 동일 장당 가중치 환산 부분을 변경한다. [ADR-010](010-five-ticket-entry-limit.md)의 실제 장수 기준 사용 상한은 유지한다.

## 배경

사용자가 게임·미션 완료 보상을 브론즈·실버·골드 응모권의 무작위 지급으로 변경하도록 요청했다. 확률 배정과 실제 지급 장수·가중치 의미를 추가 확인했다.

## 결정과 이유

- 변경 전: 게임은 일반 응모권 1장, 미션은 설정된 수량을 지급하고, 가중치 적용 이벤트는 차감 장수 자체를 가중치로 계산했다.
- 변경 후: 게임·미션 보상 건마다 등급 응모권 1장을 지급한다. 사용자 확인에 따른 획득 확률·장당 가중치는 [응모권 규칙](../02-domain/ticket.md#게임미션-보상의-등급-추첨)을 원본으로 관리한다.
- 같은 보상 건의 재시도에서는 확정된 등급을 재사용하고 지급을 중복 반영하지 않는다. 실제 장수와 가중치를 별도로 보존·표시한다.
- 정책 요청과 수치의 확인은 완료됐으나 구현·API·ERD에 대한 담당자 검토는 아직 수행하지 않았다. ADR 상태를 채택으로 표시하지 않는다.

## 검토한 대안

- 등급에 따라 일반 응모권을 여러 장 지급하는 방식: 사용자에게 두 의미를 확인했고 등급 응모권 1장과 서로 다른 가중치를 선택했다.

## 영향과 재검토 조건

- 프론트엔드: 보상 결과와 지갑에서 등급·실제 장수·가중치를 구분한다. 등급 획득 확률을 이벤트 당첨 확률로 표시하지 않는다.
- 백엔드: 보상 청구에 확정 등급을 보존하고 등급별 잔액과 차감 출처를 추적한다. 응모 장수 상한과 추첨 가중치는 분리한다.
- 추첨: 등급별 차감 장수로 가중치를 합산하고 최초 실행 스냅샷과 재추첨의 원래 가중치를 보존한다.
- API·DB 구현 변경은 포함하지 않는다. 출석·기존 응모권·반환 등급·차감 선택과 전환 시점은 [미결정 사항](../00-requirements/pending-decisions.md#등급-응모권)을 확정한 뒤 구현한다.

## 후속 결정

- 2026-10-07: 작성 당시 미결정이었던 기본·연속 출석 보상 등급은 [ADR-016](016-attendance-bronze-tickets.md)과 [출석 규칙](../02-domain/attendance.md)에 따라 브론즈 고정 지급으로 정리했다. 게임·미션 무작위 지급 정책은 유지한다.
