# ADR-005: 연속 출석의 월별 반복 미션 분리와 퀴즈·게임 보상 조건 확정

## 배경

출석·미션·게임은 응모권 지급을 발생시키는 판정 영역인데 도메인 규칙 문서가 없었다. 기능 요구사항에만 흩어져 있어 판정 기준을 기록할 위치가 없었고, 다음 세 가지가 미결정으로 남아 있었다.

- 연속 출석은 기능 요구사항의 일회성 미션 표에 기재돼 있었으나, 같은 절의 '사용자당 이벤트 기간 중 1회만 달성'이라는 정의와 맞지 않았다. 구현 범위에서 보류한 주간 미션 표에도 연속 출석이 있어 범위가 겹쳤다. 적용 일수, 출석 누락 처리, 등록 허용 범위가 모두 미정이었다.
- 브랜드 퀴즈는 '참여 또는 정답 달성'으로 기재돼 판정 기준이 확정되지 않았다.
- 게임 보상 획득에 필요한 플레이 횟수·점수 조건이 미정이라 지급 판정을 정의할 수 없었다.

## 결정과 이유

### 연속 출석

- 변경 전: 일회성 미션 표에 '장기 연속 출석'으로 기재했고 적용 일수는 미정이었다.
- 변경 후: 월별 반복 미션으로 분리한다. 연속 출석 일수는 매월 1일 0으로 초기화하고, 출석하지 않은 날이 있으면 0으로 돌아간다. 7일·14일·28일 도달 시 각각 응모권 1장·3장·7장을 지급한다. 같은 달에 같은 단계의 보상은 한 번만 지급하며, 상위 단계 달성이 하위 단계 보상을 대체하지 않는다. 사용자당 한 달 최대 11장이다. 월 단위로 초기화하므로 28일을 초과하는 단계는 등록하지 않는다.

매월 반복 달성하는 미션을 '사용자당 1회'로 정의된 일회성 미션에 둘 수 없어 범주를 분리했다. 28일을 상한으로 둔 것은 2월을 포함한 모든 달에서 달성할 수 있도록 하기 위해서다.

### 브랜드 퀴즈

- 변경 전: 참여 또는 정답 달성 중 어느 것인지 재확인이 필요했다.
- 변경 후: 제출한 답이 정답인 경우에만 달성으로 인정한다. 오답은 달성으로 기록하지 않으며 사용자는 다시 답변할 수 있다. 재도전으로 정답을 맞혀도 보상은 한 번만 지급한다.

설문이 '최종 제출 시 완료'로 확정된 상태에서 퀴즈도 제출만으로 인정하면 두 미션의 달성 조건이 같아진다.

### 게임 보상

- 변경 전: 보상 획득에 필요한 플레이 횟수·점수 조건이 미정이었다.
- 변경 후: 서버가 유효로 판정한 플레이가 해당 보상 기준일에 한 번 이상 있으면 보상을 지급한다. 점수나 플레이 횟수에 따른 차등 지급은 하지 않으며 지급 수량은 항상 1장이다.

제공할 게임 종류와 규칙이 확정되지 않아 점수 커트라인을 정할 수 없다. 사용자별·게임별 하루 1장 상한이 이미 지급 남발을 막고 있다.

## 검토한 대안

- **연속 출석 단계의 반복 수령 허용**: 같은 달에 7일 연속을 여러 번 달성하면 그때마다 지급하는 방안을 검토했다. 7일 출석 후 하루 쉬는 패턴이 한 달 개근보다 많은 보상을 받게 되어, 출석을 유도하려는 미션이 출석을 끊도록 유도한다. 채택하지 않았다.
- **최고 단계만 지급**: 상위 단계 달성 시 하위 단계 보상을 지급하지 않는 방안을 검토했다. 7일·14일 단계가 중간에 실패한 사용자를 위한 보상으로만 남아 단계 구조의 의미가 약해진다. 채택하지 않았다.
- **28일 대신 30일**: 2월에는 달성이 불가능해 매년 한 달은 해당 단계가 성립하지 않는다. 달마다 기준 일수를 다르게 하는 방안도 검토했으나 앞의 두 단계는 고정 일수이고 마지막만 가변이 되어 규칙이 일관되지 않는다. 채택하지 않았다.
- **게임 보상에 점수 커트라인 적용**: 게임 종류·규칙이 확정된 뒤에만 커트라인을 정할 수 있어 현 시점에는 적용하지 않는다. 보류이며 기각이 아니다.
- **연속 출석 미션 자체를 보류**: 주간 미션과 함께 보류 범위로 넘기는 방안을 검토했으나, 기능 요구사항에 이미 포함돼 있어 범위를 줄이지 않았다.

## 영향과 재검토 조건

- 백엔드: 출석 기록에서 연속 일수를 판정하고, 단계별 지급이 같은 달에 한 번만 반영되도록 보장해야 한다. 퀴즈는 정답 판정 후 지급하며 오답 시 달성 기록을 생성하지 않는다.
- 프론트엔드: 미션 목록에서 일회성 미션과 월별 반복 미션을 구분해 노출하고, 연속 출석의 단계별 진행 상태를 표시한다.
- 백오피스: 연속 출석 단계별 달성 일수와 보상 응모권 수, 퀴즈 문항과 정답을 관리한다.
- 정답 정보는 사용자에게 제공하는 응답에 포함하지 않는다.
- 게임 보상에 점수 조건을 도입하려면 게임 종류·규칙이 확정된 뒤 이 결정을 다시 검토한다.
- 미션의 소속 범위, 미션별 보상 수량, 퀴즈 재도전 횟수 제한은 확정하지 않았으며 [미결정 사항](../00-requirements/pending-decisions.md#미션)에서 관리한다.
- 게임 보상 기준일의 시간대는 확정하지 않았다. 기본 출석은 00:00 UTC 기준이다.

상세 규칙은 [미션 도메인 규칙](../02-domain/mission.md)과 [게임 도메인 규칙](../02-domain/game.md)을 따른다.
