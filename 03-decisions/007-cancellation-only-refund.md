# ADR-007: 일시 중단에는 응모권을 반환하지 않음

> 후속 결정: [ADR-008](008-finalized-service-policies.md)이 관련 미결정 항목과 일부 정책을 갱신했다. 아래 본문은 당시 결정 기록이며 현재 기준은 ADR-008과 도메인 문서를 따른다.

- 상태: 채택
- 작성자 / 날짜: 사용자 선택에 따라 Codex 정리 / 2026-09-21
- 관련 작업 기록: [미결정 사항 순차 확정](../04-worklogs/2026-09-21-pending-decisions.md)

## 변경 전과 변경 후

- 변경 전: 취소 시 반환은 확정됐지만 일시 중단 시 반환 여부는 미정이었다.
- 변경 후: 일시 중단만으로는 반환하지 않고 최종 취소 시 반환한다. 중단 중 마감 시각 도달에 따른 자동 취소도 포함한다. 취소 후 후속 처리로 반환하는 방식은 유지한다.

## 근거와 대안

사용자가 A(취소될 때만 반환)를 선택했다. 일시 중단 시 반환하거나 일정 시간 경과 후 반환하는 대안은 재개 시 재차감·응모 처리 규칙이 추가로 필요해 채택하지 않았다.

## 영향과 남은 결정

- 백엔드: 일시 중단으로 반환 처리를 생성하지 않는다. 최종 취소 시 중복 반환 방지 규칙을 적용한다.
- 프론트엔드·백오피스: 일시 중단과 취소 후 반환 대기를 구분해 안내한다.
- 추첨 대상 제외에 따른 반환 등 다른 사유의 반환 규칙은 변경하지 않는다.
- 재개 시 기존 응모 처리와 반환 완료 시한은 아직 미정이다.

기준 규칙은 [이벤트 도메인 규칙](../02-domain/event.md)을 따른다.
