# ADR-010: 일반 가중치 적용 이벤트의 응모권 사용 상한 5장

- 상태: 채택
- 날짜: 2026-09-22
- 근거: 사용자가 기존 '여러 장' 표현을 최대 5장으로 변경하도록 요청했다.

## 변경 전과 변경 후

- 변경 전: 여러 장 사용과 추가 응모는 허용하지만 일반 이벤트의 사용 수량 상한이 명확하지 않았다.
- 변경 후: 일반 가중치 적용 이벤트는 사용자당 이벤트별 누적 최대 5장으로 제한한다. 추가 응모도 합산하므로 요청을 나눠 상한을 초과할 수 없다.
- 월말 소진용 이벤트의 상한 없음 예외와 가중치 미적용 이벤트의 1회·1장 정책은 유지한다.
- 가중치 환산식·가중치 값의 상한은 응모권 사용 수량 상한과 다른 항목이며 기존 보류 상태를 유지한다.

## 영향

- 프론트엔드: 이벤트별 누적 사용량과 남은 사용 가능 수량 표시. 3장 사용 후 최대 2장 추가 가능, 5장 사용 후 추가 응모 불가.
- 백엔드: 단일 요청 수량뿐 아니라 사용자·이벤트별 누적 사용량을 동시 요청에서도 검증한다. 월말 소진용 이벤트 예외와 유효 보유량 검증을 함께 적용한다.
- API·DB 구현은 이번 문서 수정에 포함하지 않는다.
