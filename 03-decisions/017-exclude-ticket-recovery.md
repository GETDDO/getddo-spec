# ADR-017: 부정 획득 응모권 회수 기능 제외

- 상태: 제안
- 작성자 / 날짜: Codex / 2026-10-07
- 검토자: 담당자 검토 대기

- 대체한 ADR / 대체된 ADR: 해당 없음

## 배경

GD-93 ERD는 회수 기능을 제외했지만 공용 요구사항에는 부정 획득분 회수가 남아 있었다. 사용자가 회수 기능 제외를 최종 정책으로 확인했다.

## 결정과 이유

- 변경 전: 관리자가 부정을 확인하면 원본 지급분을 지정해 회수할 수 있었다.
- 변경 후: 부정 획득분 회수도 이번 버전에서 제외한다. 회수 대상 조회·회수 결정·실제 회수 처리와 회수 알림을 제공하지 않는다.
- 확정 정책은 [구현 범위](../00-requirements/scope.md)와 [응모권 규칙](../02-domain/ticket.md#응모권-회수-제외)에 반영한다. 사용자 정책 확인과 담당자의 API·구현 검토를 구분해 ADR은 제안 상태로 둔다.
- 이벤트 취소·응모 제외에 따른 반환, 점수 무효화, 당첨 취소·재추첨은 기존 정책을 유지한다.

## 검토한 대안

기존 spec의 부정 획득분 회수 유지와 GD-93의 회수 제외를 대조했다. 사용자가 제외를 선택했으며 별도 기술 대안 검증은 수행하지 않았다.

## 영향과 재검토 조건

- 프론트엔드: 회수 대상 조회·회수 실행 화면과 회수 알림을 이번 버전 범위에서 제외한다.
- 백엔드: 회수 API와 신규 회수 처리·알림 생성을 제외한다. GD-93의 회수 제외 모델과 공용 명세의 충돌을 해소한다.
- 기존 운영 코드·Flyway·저장 이력은 이번 문서 변경으로 삭제하거나 수정하지 않는다. 기존 REVOKE 이력과 알림 유형의 호환 처리가 필요하면 담당자가 별도로 확인한다.
- 회수 기능이 없으므로 지급된 부정 획득분도 회수로 차감하지 않는다. 재도입 시 지급 출처·반환·이력·동시성 계약을 다시 검토한다.
