# ADR-025: 플래티넘 응모권 추가와 획득 확률 조정

- 상태: 제안
- 작성자 / 날짜: Codex / 2026-10-17
- 검토자: 담당자 검토 대기
- 관련 작업 기록 / PR: [플래티넘 공용 스펙 반영](../04-worklogs/2026-10-17-platinum-ticket-grade.md) / PR 미생성
- 대체한 ADR / 대체된 ADR: [ADR-014](014-random-ticket-grades.md)의 등급 구성·획득 확률 부분 대체

## 배경

사용자가 게임·미션 보상에 플래티넘을 추가하고 획득 확률과 장당 가중치를 확인한 뒤 공용 스펙만 수정하도록 요청했다.

## 결정과 이유

- 변경 전: 보상 등급은 브론즈·실버·골드 3종이었다.
- 변경 후: 플래티넘을 추가하고 브론즈 확률을 조정한다. 확정 수치는 [응모권 규칙](../02-domain/ticket.md#게임미션-보상의-등급-추첨)의 표를 원본으로 관리한다.
- 사용자가 선택한 수치를 반영한다. 실제 지급 수량은 보상 건당 1장이고 등급별 가중치와 구분한다.
- 출석 브론즈 고정 지급, 보상 제한·만료·응모 장수 상한은 유지한다. 최초 추첨 스냅샷과 기존 지급 결과를 소급 변경하지 않는다.

## 검토한 대안

- 플래티넘 획득 확률 0.5% 또는 1%, 장당 가중치 10을 검토했다. 사용자는 0.02%와 가중치 10을 선택했다.

## 영향과 재검토 조건

- 프론트엔드: 보상 결과·지갑·응모 선택·이력·관리자 조회의 등급 표시와 맵 처리를 확인해야 한다.
- 백엔드: 윤태형의 지급·잔액·차감·반환·응모, 석종수의 추첨 가중치·스냅샷, 전민규의 게임 보상 연동·관리자 표시가 영향받는다. 코드·DB 변경은 이번 작업에 포함하지 않는다.
- 수치에 대한 사용자 확인과 구현·연동 검증을 구분한다. 서비스 적용 시점과 담당자 후속은 [미결정·후속 사항](../00-requirements/pending-decisions.md#등급-응모권)을 따른다.
