# ADR-020: 게임별 최소 보상 점수

- 상태: 채택
- 작성자 / 날짜: 사용자 결정에 따라 Codex 정리 / 2026-10-12
- 검토자: 전민규 사용자 명시적 결정
- 관련 작업 기록 / PR: [작업 기록](../04-worklogs/2026-10-12-game-reward-minimum-score.md)
- 대체한 ADR / 대체된 ADR: [ADR-005](005-reward-domain-separation.md)의 최소 점수 없는 게임 보상 조건만 대체

## 배경

기존에는 점수와 무관하게 유효한 플레이가 있으면 일일 보상 자격을 인정했다. 사용자는 타꼬런의 스테이지 2 진입 시점으로 제시한 400점과 글자색깔 맞추기 50점을 최소 기준으로 지정했다. 스테이지 자체의 검증 계약을 확정하는 결정은 아니다.

## 결정과 이유

- 변경 전: 유효한 0점 완료도 보상 자격이 있었다.
- 변경 후: 타꼬런은 한 판 400점 이상, 글자색깔 맞추기는 한 판 50점 이상인 유효 완료만 보상 자격이 있다.
- 기준 미만도 유효 기록과 통계는 남기고, 청구·지급·일일 보상 기회 소진은 하지 않는다.
- 게임별 KST 하루 1회 무작위 등급 응모권 1장과 최초 결과 재시도 정책은 유지한다.

현재 기준은 [게임 도메인 규칙](../02-domain/game.md#보상-지급)이다.

## 검토한 대안

기존 무점수 제한 정책 대신 사용자가 요청한 게임별 최소 점수를 채택했다. 별도 대안 검토 없음.

## 영향과 재검토 조건

- 백엔드: 유효성·통계 처리와 보상 자격을 구분하고, 최소 점수 미달이면 청구 생성과 응모권 지급 호출을 생략한다. 공통 지급 서비스의 등급·수량·만료 규칙은 바꾸지 않는다.
- 프론트엔드: 게임별 최소 점수 안내와 정상 완료했지만 보상이 없는 결과 표시가 필요하다. 50점 미만의 색깔 게임 결과 예제는 `reward=null`로 변경한다.
- 기존 확정 결과·지급 이력은 소급 변경하지 않는다. 운영 중 정책 변경의 적용 시점은 기존의 다음 일일 기준일 규칙을 따른다.
- 보상 기준의 확정과 실제 결과 API·프론트 연동 완료는 구분한다. 타꼬런 상세 종료·검증 계약은 후속 작업이다.
