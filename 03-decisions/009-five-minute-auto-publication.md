# ADR-009: 응모 마감 후 5분 검토 및 자동 최초 발표

- 상태: 채택
- 날짜: 2026-09-22
- 근거: 사용자 요청 — 마감 후 5분 타이머를 보여주고 그 안에 어뷰징·예외 사항을 처리한 뒤 3등부터 바로 발표한다.
- 대체 범위: ADR-008의 마감 즉시 자동 추첨, 기존 미사용 이벤트 수동 최초 추첨 및 관리자 승인 후 최초 발표 규칙. 사후 재추첨·공개 명단 갱신 정책은 유지한다.

## 변경 전과 변경 후

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 최초 추첨 진행 | 사용 이벤트는 마감 즉시 자동, 미사용 이벤트는 관리자 수동 실행 | 두 유형 모두 마감 후 5분 검토 시간 동안 결과 준비 |
| 최초 공개 | 관리자 승인 후 발표 | 마감 시각 + 5분에 자동 발표 시작 |
| 대기 화면 | 응모 마감 · 결과 발표 대기 | 결과 발표까지 05:00부터 카운트다운 |
| 발표 순서 | 서버 확정 결과의 역순 표시 | 5분 종료 후 3등 → 2등 → 1등 발표. 실제 선정 순서는 1등 → 2등 → 3등 유지 |

## 영향과 경계

- 프론트엔드: 서버 발표 예정 시각 기준 카운트다운, 재접속 시 남은 시간 복원, 서버 공개 결과에 따른 발표 연출을 적용한다.
- 백엔드: 5분 내 탐지·검토·예외 처리와 결과 준비, 최초 공개의 중복 방지, 취소 시 공개 방지, 실제 공개에 연결된 알림을 처리한다.
- 관리자: 최초 발표 승인 동작을 정상 흐름에서 제거하고 5분 검토 시간에 어뷰징·예외를 처리한다. 탐지만으로 부정을 확정하는 정책으로 바꾸지 않는다.
- 기존의 즉시 추첨·수동 최초 발표 흐름은 이번 사용자 변경으로 대체한다. 새로운 재추첨은 기존 정책을 따른다.
- 장애나 정합성 오류로 결과 준비에 실패한 경우의 안내·복구·취소 기준은 [미결정 사항](../00-requirements/pending-decisions.md#추첨과-결과-발표)에 남긴다. 장애 처리 방식을 임의로 확정하지 않는다.
