# ADR-001: 추첨 인원·정합성과 동일 실행 결과 보존

- 상태: 채택

- 관련 작업 기록 / PR: 로컬 요구사항 수정, PR 미생성

## 배경

기존 명세는 “재추첨해도 당첨자가 일정해야 한다”를 같은 당첨자와 당첨 순서를 다시 산출해야 한다는 의미로 해석했다. 사용자는 이 요구가 설정된 당첨 인원과 데이터 정합성을 보장한다는 의미임을 명시했다.

## 결정과 이유

추첨 결과를 다시 산출해 원본과 비교하는 요구와 이를 위한 시드 등 재현 자료 보존 요구를 제거한다. 경품별 인원 준수, 유효 후보 내 선정, 중복 당첨 방지, 실행별 후보·조건 스냅샷과 결과 이력 보존은 유지한다.

새로운 재추첨은 별도 실행이며 결과가 달라질 수 있다. 이미 확정된 동일 실행의 재시도·동시 요청에는 저장된 결과를 반환한다. 당첨 취소에 따른 재추첨은 취소되지 않은 기존 당첨자와 경품을 유지하며 빈 자리만 보충한다.

## 검토한 대안

별도 대안 검토 없음. 사용자가 정정한 요구사항의 의미를 반영한다.

## 영향과 재검토 조건

백엔드는 확정 결과 조회와 새로운 추첨 실행을 구분하고 실행 중복을 방지해야 한다. 백오피스는 실행 이력과 정합성 검증 결과를 제공한다.

백엔드에서 결과를 모두 확정하고 프론트엔드에서는 3등 → 2등 → 1등 순서로 표시한다. 화면 표시 순서는 실제 선정 순서를 의미하지 않으며, 관리자 승인 후 공개하는 기존 정책은 유지한다.

실제 선정 순서, 후보 부족 시 경품 배정 우선순위, 재추첨 후보·가중치 기준과 재발표 정책은 미결정 사항으로 유지한다. 현재 작업공간에는 추첨 구현이나 재현용 해시 비교 로직이 없으므로 문서를 수정했다.

상세 규칙은 [추첨 도메인 규칙](../02-domain/drawing.md)을 따른다.

## 후속 결정
