# ADR-003: 중단 중 마감 시각 도달 시 이벤트 자동 취소

> 후속 결정: [ADR-008](008-finalized-service-policies.md)이 관련 미결정 항목과 일부 정책을 갱신했다. 아래 본문은 당시 결정 기록이며 현재 기준은 ADR-008과 도메인 문서를 따른다.

- 상태: 채택
- 작성자 / 날짜: 사용자 지시에 따라 Codex 정리 / 2026-09-21
- 검토자: 사용자 명시적 결정, 별도 팀 검토 이력 없음
- 관련 작업 기록 / PR: 로컬 명세 수정, PR 미생성
- 대체한 ADR / 대체된 ADR: 해당 없음. ADR-002의 취소 허용 정책을 보완한다.

## 배경

중단 중 응모 마감 시각이 지난 이벤트의 처리와 재개 허용 여부는 미결정이었다. 사용자가 이 경우 이벤트를 취소하도록 결정했다.

## 결정과 이유

- 변경 전: 중단 후 재개 원칙만 있었고, 중단 중 마감 시각이 지났을 때의 처리는 미정이었다.
- 변경 후: 중단 중 응모 마감 시각에 도달하면 시스템이 자동 취소하며, 이후 재개할 수 없다. 취소에 따른 기존 응모권 반환 규칙을 적용한다.

사용자의 확정 요구사항을 반영한다. 기준 정책은 [이벤트 도메인 규칙](../02-domain/event.md)을 따른다. 모든 상태에서 관리자 취소를 허용한 [ADR-002](002-event-cancellation-states.md)는 유지한다.

## 검토한 대안

마감 시각이 지나면 응모를 마감하고 재개를 금지하는 방안을 대화에서 제안했다. 사용자는 마감 처리 대신 취소를 선택했다. 별도 선택 이유는 전달되지 않았다.

## 영향과 재검토 조건

- 백엔드: 중단 중 마감 시각에 도달한 이벤트를 자동 취소하고 재개를 허용하지 않는다. 응모권 반환은 기존 정책에 따라 후속 처리한다.
- 프론트엔드·백오피스: 취소된 이벤트의 재개를 제공하지 않고 취소 상태와 반환 처리 이력을 표시한다.
- 사용자 화면: 해당 이벤트를 결과 발표 대기가 아닌 취소 상태로 표시한다.
- 이미 마감된 이벤트를 중단하는 경우의 취소 처리 시점, 마감 전 재개의 나머지 조건과 반환 관련 미결정 사항은 [미결정 사항](../02-domain/event.md)에서 관리한다.
