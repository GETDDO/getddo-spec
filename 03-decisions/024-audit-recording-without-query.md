# ADR-024: 감사 기록 유지와 공통 감사 조회 제외

- 상태: 제안 — Codex 작성, 담당자 문서 확인 전
- 정책 근거: 2026-10-15 사용자가 공통 감사 조회 제외와 기록 유지를 명시적으로 요청했다. 정책 결정과 이 ADR 문서의 검토 상태를 구분한다.
- 작성자: 사용자 요청에 따라 Codex 정리
- 기준: [구현 범위](../00-requirements/scope.md), [감사 기록 명세](../05-api/audit.md)

## 결정

| 변경 전 | 변경 후 |
| --- | --- |
| AU01/AU02 공통 감사 목록·검색·상세 제공 | 이번 버전에서 제외 |
| 공통 감사 전용 화면 연결 | 이번 버전에서 제외 |
| 업무 변경과 함께 감사 기록 저장 | 유지 |
| 기존 감사 테이블·저장 이력 | 유지 |
| 개별 업무의 실패·확인·공개·취소 내역 조회 | 기존 업무 계약 유지 |

사용자가 감사 조회를 제공하지 않으므로 조회 구현을 제거하고 감사 명세를 표로 다시 정리하도록 요청했다. 조회 제공 결정만 대체하며 저장 기반·업무 호출·트랜잭션 정책은 변경하지 않는다.

## 영향

- GD-207 조회 코드·테스트·조회 응답 및 오류 계약을 제거한다. 기존 기록 코드·저장 테스트·DB는 유지한다.
- FE 공통 감사 화면은 AU01/AU02를 연결하지 않는다. FE 코드 자체 변경은 담당자 후속이다.
- 추첨 명세의 공통 감사 조회 재사용 전제를 제거한다. 추첨 자체의 운영 내역·실패 조회나 감사 기록을 삭제하는 결정이 아니다.
- 과거 채택·검증 기록은 당시 이력으로 보존하며 현행 범위는 이 ADR과 감사 기록 명세를 따른다.
