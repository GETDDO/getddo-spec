# ADR-021: 이벤트 연결 배너의 관리자 수동 삭제

- 상태: 채택 — 사용자 확정 정책 재확인
- 작성자 / 날짜: 사용자 요청에 따라 Codex 정리 / 2026-10-14 (KST)
- 검토자: 사용자 정책 확인. 별도 팀 검토 이력은 기록되지 않음
- 관련 작업 기록 / PR: [정책 최신화 기록](../04-worklogs/2026-10-14-manual-banner-deletion.md), PR 미생성
- 대체한 ADR: [ADR-012](012-event-registration-and-editing-rules.md)의 이벤트 삭제 시 연결 배너 자동 삭제 정책만 대체

## 배경

사용자는 이벤트 연결 배너를 관리자가 수동 삭제하기로 이미 확정했다고 재확인했다. 공용 이벤트 규칙과 API, ADR-012에는 연결 배너 자동 삭제 문구가 남아 있어 구현 방침과 달랐다. 사용자는 공용 명세와 ADR에서 배너 정책만 최신화하고 알림 정책은 현재대로 유지하도록 요청했다.

## 결정과 이유

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 이벤트 삭제 시 연결 배너 | 이벤트 삭제와 함께 자동 삭제 | 이벤트 삭제와 별개로 관리자가 확인해 수동 삭제 |
| 연결 배너가 남아 있는 이벤트 삭제 | 연결 배너를 이유로 삭제를 제한하지 않음 | 기존 제한 없음 유지 |

사용자가 확정한 관리 방식을 반영한다. 기준 정책은 [이벤트 규칙](../02-domain/event.md#수정-및-삭제-제한)이며 삭제 가능 조건과 알림 정책은 이번 결정으로 변경하지 않는다.

## 검토한 대안

- 이벤트 삭제 시 배너 자동 삭제: 기존 명세의 방식이며 사용자 확인에 따라 수동 관리로 대체한다.
- 그 밖의 대안에 대한 별도 결정은 없다.

## 영향과 재검토 조건

- 백엔드는 이벤트 삭제에 배너 자동 삭제나 연결 배너 존재에 따른 삭제 제한을 추가하지 않는다.
- 관리자는 필요 없어진 배너를 별도 배너 관리 기능에서 삭제한다. 이벤트 삭제만으로 배너 목록이 정리된다고 가정하지 않는다.
- 수동 정리를 누락하면 삭제된 이벤트를 가리키는 배너가 남을 수 있다. 자동 정리를 다시 채택할 때는 연결 정보와 삭제 처리를 함께 검토한다.
- 기존 ADR·작업 기록은 당시 결정으로 보존하고 현행 정책은 이 ADR과 이벤트 규칙을 따른다.
