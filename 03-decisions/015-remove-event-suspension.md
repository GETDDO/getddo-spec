# ADR-015: 이벤트 일시 중단·재개 제외

- 상태: 채택 — 사용자 요구사항 변경 반영, 별도 팀 검토 이력 없음
- 작성자 / 날짜: 사용자 지시에 따라 Codex 정리 / 2026-10-06
- 관련 작업 기록: [이벤트 중단 기능 제외](../04-worklogs/2026-10-06-remove-event-suspension.md)
- 대체 범위: [ADR-003](003-suspended-event-deadline.md), [ADR-007](007-cancellation-only-refund.md), [ADR-008](008-finalized-service-policies.md)의 이벤트 중단·재개 정책과 [ADR-012](012-event-registration-and-editing-rules.md)의 중단 상태 수정 제한을 대체한다. 취소·반환과 다른 정책은 유지한다.

## 변경 전과 변경 후

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 이벤트 운영 | 일시 중단과 재개를 제공하고 중단 중 마감 시 자동 취소 | 일시 중단·재개를 제공하지 않음 |
| 중단 시간 | 중단 시각을 기록하고 별도 중단 시간 설정은 없음 | 중단 기능에 연결된 시간 설정·응답을 제공하지 않음 |
| 최종 취소 | 상태와 관계없이 관리자 취소, 차감분 반환 | 유지 |

사용자가 이벤트 중단과 일시중단 시간을 요구사항에서 제외하도록 지시했다. 일시 중단 상태를 유지하는 대안은 채택하지 않았다. 별도 변경 이유는 전달되지 않았다.

## 영향

- 프론트엔드·백오피스: 이벤트 중단·재개 조작과 중단 시간 표시를 제공하지 않는다. 취소와 반환 이력 조회는 유지한다.
- API: AE06·AE07을 제외하고 기존 AE08 취소 식별자는 유지한다. 이벤트 응답에서 중단 상태·시각·직전 상태를 제공하지 않는다.
- 백엔드: 기존 `SUSPENDED`, `suspended_at`, `suspended_from_status` 및 관련 API·자동 취소 흐름을 새 요구사항과 맞춰 검토한다. 기존 DB·코드 변경은 이 공용 명세 작업에 포함하지 않는다.
- 추첨 실행의 장애 후 재개는 이벤트 운영의 재개와 별개이므로 유지한다.

현재 기준은 [기능 요구사항](../00-requirements/functional-requirements.md#신규-확정-관리-기능)과 [이벤트 규칙](../02-domain/event.md)을 따른다.
