# ADR-008: 순차 질의로 확정한 서비스 정책 일괄 반영

- 상태: 부분 대체 — 최초 추첨·발표 시점은 [ADR-009](009-five-minute-auto-publication.md)로 변경. 일일·월간 시간 기준은 [KST 자정 기준](../00-requirements/functional-requirements.md#공통-시간-기준과-화면-표시)으로 변경. 그 외 정책은 유지
- 작성자 / 날짜: 사용자 최종 답변에 따라 Codex 정리 / 2026-09-21
- 관련 작업 기록: [미결정 사항 순차 확정](../04-worklogs/2026-09-21-pending-decisions.md)
- 대체 범위: ADR-006의 미션 재달성·반복 주기·문항 버전 방식, ADR-007과 ADR-003의 후속 반환 방식, ADR-005의 고정 출석 수치 해석을 부분 대체한다. 이전 기록은 당시 결정을 보존한다.

## 배경과 결정 근거

사용자는 미결정 목록을 순서대로 검토하며 선택지에 답했고, 중간에 정책을 정정했다. 첫 반환 결정만 즉시 반영한 뒤 나머지는 기억해 두었다가 ‘끝났다’에 일괄 반영하도록 요청했다. 최종 답변이 앞선 선택과 다르면 최종 답변을 기준으로 한다.

## 검토한 대안과 채택하지 않은 내용

- 일시 중단 시 반환, 재개 시 재신청, 반환 후속 배치 대신 응모 유지·취소 즉시 반환을 선택했다.
- 미션 반복 주기·문항 버전 재달성은 처음 선택했지만 사용자가 수동 신규 미션·반복 없음으로 정정했다.
- 자동 추첨을 관리자 검토 완료까지 보류하는 추천안 대신, 사용자는 미검토 포함 즉시 추첨을 선택했다.
- 낙첨자 부정으로 전체 재추첨, 재추첨 시 자격·가중치 전면 재산정은 채택하지 않았다.
- 재추첨 30일 제한은 채택하지 않고 관리자 부정 확인 시 즉시 처리하기로 했다.
- 기록 보관 1년 제안 대신 사용자가 5년을 선택했다. 개인정보 익명화/집계 방안은 선택하지 않았으며 탈퇴 기능 없음만 확정했다.
- 가중치 1장=1, 배너 5MB, CAPTCHA 도입 등 제안은 확정 정책에 포함하지 않는다.

## 영향

- 백엔드: 미션 사용자·미션 유일 제약, 제출 도착 시각 보존, 게임 플레이 멱등성, 취소·반환 정합성, 지급별 만료일 및 정책 적용 이력이 필요하다.
- 프론트엔드: 반복 미션 표시를 제거하고 오답 재도전은 유지한다. 정확한 만료 일시와 마스킹된 공개 명단을 표시하며 관리자 재추첨 과정을 사용자에게 노출하지 않는다.
- 백오피스: 미션 수동 등록, 출석 정책 적용 시점, 관리자 전용 재추첨 연출·확인, 사용자 정보 읽기 전용을 반영한다.
- 어뷰징 기준 담당자 수정은 확정 정책의 운영 작업이다. 가중치·마스킹·게임 세부 규칙·배너·누락 원문 및 미선택 개인정보 처리 방식은 [후속 목록](../00-requirements/pending-decisions.md)에 구분한다.

상세 기준은 [기능 요구사항](../00-requirements/functional-requirements.md)과 각 [도메인 규칙](../02-domain/README.md)을 따른다. 실제 API·DDL 구현은 이번 문서 반영에 포함하지 않는다.
