# ADR-019: 관리자 사유에 따른 개별 당첨 취소·빈 자리 재추첨

- 상태: 제안
- 작성자 / 날짜: Codex / 2026-10-12
- 검토자: 사용자 정책 확정 — ADR 문서 담당자 검토 대기
- 관련 작업 기록 / PR: [정책 반영 기록](../04-worklogs/2026-10-12-admin-award-cancellation.md) / GD-87·GD-138, PR 없음
- 대체한 ADR / 대체된 ADR: ADR-008의 취소 사유 제한 및 ADR-018의 당첨 취소·재추첨 유지 여부 후속 확인 부분을 구체화. 추첨 전 제외 폐지는 유지.

## 배경

사용자가 어뷰징과 관계없이 관리자가 개별 당첨을 취소하고 빈 자리만 재추첨할 수 있도록 요청했다. 이후 응모권 반환 가능성을 검토했으나 반환·회수하지 않는 문구를 명시적으로 선택하고 spec 반영·push를 요청했다. 전체 당첨 취소 후 처음부터 재추첨은 고려할 사항이 많아 추후 추가 예정으로 남기기로 했다.

## 결정과 이유

- 변경 전: 확인된 자격 미달·어뷰징을 당첨 취소 사유로 제한하고 사후 취소·재추첨 유지 여부를 후속 확인으로 남겼다.
- 변경 후: 관리자는 취소 사유를 기록하여 개별 당첨을 취소하고 빈 자리만 재추첨할 수 있다. 어뷰징·자격 미달 확인을 필수 조건으로 요구하지 않는다. 당첨 취소·재추첨을 이유로 응모권을 반환하거나 회수하지 않는다.
- 유지되는 당첨자·경품, 최초 가중치, 취소와 실행 등록의 원자성, 실패한 동일 실행 재개와 확정 결과 불변은 유지한다.
- 전체 당첨 취소·처음부터 전체 재추첨은 추후 추가 예정이며 이번 구현·완료 범위에서 제외한다. 관련 후보·공개·이력 정책은 아직 확정하지 않는다.
- 정책 원본은 [추첨 규칙](../02-domain/drawing.md#재추첨)과 [응모권 규칙](../02-domain/ticket.md#응모권-회수-제외)이다. 사용자 정책 확정과 구체적인 API·구현·ADR 문서 검토를 구분해 AI 작성 ADR은 제안 상태로 시작한다.

## 검토한 대안

어뷰징·자격 미달에 한정한 기존 취소와 일반 관리자 취소를 비교했다. 취소 응모권 반환 방안을 대화에서 제안했으나 사용자가 반환·회수 없음으로 선택했다. 전체 취소·전체 재추첨은 추후 추가로 보류했다. 별도 기술 대안이나 운영 시나리오 검증은 수행하지 않았다.

## 영향과 재검토 조건

- GD-138은 개별 취소·빈 자리 재추첨 생성 및 관리자 진입점, GD-87은 최초 추첨·재추첨의 공통 실패·재시도·동일 실행 재개 기반을 담당하도록 Jira 계획을 정리했다. 상세 상태·잠금·Repository 계약은 구현 전에 조율한다.
- AD05의 일반 취소에 부정 확정이나 abuseCaseId 연결을 필수로 요구하지 않는다. 관리자 권한·취소 사유·감사와 오류·멱등 상세 계약은 확인 후 구현한다. 이번 문서 변경은 코드 구현 완료를 의미하지 않는다.
- 이벤트 취소에 따른 응모권 반환과 개별 당첨 취소를 구분한다. 신규 당첨 취소 반환·회수 원장이나 API를 만들지 않는다.
- 지급 전 차단 기준·범위, 사후 게임 점수 무효화·판단 근거 연결, 5분 일정은 기존 후속 확인을 유지한다. 관리자가 사유를 기록하는 취소와 자동 어뷰징 제외를 구분한다.
- 과거 판단·추첨·공개·응모권 이력과 기존 Flyway를 삭제하거나 소급 변경하지 않는다. 알림 문서 두 파일과 GD-71은 이번 작업 범위에서 제외한다.
