# ADR-016: 기본·연속 출석 보상의 브론즈 응모권 지급

- 상태: 제안
- 작성자 / 날짜: Codex / 2026-10-07
- 검토자: 담당자 검토 대기
- 관련 작업 기록 / PR: [출석 브론즈 보상 반영](../04-worklogs/2026-10-07-attendance-bronze-tickets.md) / PR 미생성
- 대체한 ADR / 대체된 ADR: 해당 없음. [ADR-014](014-random-ticket-grades.md)의 출석 등급 후속 항목을 보완한다.

## 배경

게임·미션의 무작위 등급 지급 정책을 정리한 뒤 출석 보상의 등급은 미결정으로 남아 있었다. 사용자가 출석에는 브론즈 응모권을 지급하도록 요청했다.

## 결정과 이유

- 변경 전: 기본·연속 출석 보상의 응모권 등급은 미결정이었다.
- 변경 후: 사용자 요청에 따라 기본·연속 출석 보상을 브론즈로 고정 지급한다. 지급 수량과 가중치의 기준은 [출석 규칙](../02-domain/attendance.md)으로 관리한다.
- 게임·미션의 무작위 등급 지급과 기존 출석 수량·중복 방지 정책은 유지한다.
- 사용자 정책 요청은 확인했으나 API·ERD·구현에 대한 담당자 검토는 수행하지 않았다. ADR은 제안 상태로 기록한다.

## 검토한 대안

별도 대안 검토 없음. 사용자의 브론즈 고정 지급 요청을 반영했다.

## 영향과 재검토 조건

- 프론트엔드: 기본·연속 보상을 브론즈와 실제 지급 장수로 표시하고, 등급별 잔액·이력과 연결한다.
- 백엔드: 출석 지급 결과에 브론즈 등급을 보존하고 공통 등급별 지급·잔액 계약과 연결한다.
- 공개 API 필드와 데이터 모델은 담당자 검토 후 반영한다. 이번 작업은 명세만 변경한다.
- 기존 무등급 지급분의 전환·적용 시점, 응모 차감 등급 선택과 반환 등급은 [미결정 사항](../00-requirements/pending-decisions.md#등급-응모권)에 남긴다.
