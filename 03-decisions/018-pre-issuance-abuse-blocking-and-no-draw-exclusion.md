# ADR-018: 지급 전 검증·차단 기록 중심 전환과 추첨 제외 폐지

- 상태: 채택
- 작성자 / 날짜: Codex / 2026-10-11
- 검토자: 사용자 — 2026-10-11 이번 정책 변경 검토 완료 및 push 요청
- 관련 작업 기록 / PR: [정책 반영 기록](../04-worklogs/2026-10-11-pre-issuance-abuse-blocking.md) / PR 없음
- 대체한 ADR / 대체된 ADR: ADR-008의 관리자 참여 허용·추첨 제외, ADR-007·ADR-017에 언급된 제외 반환 부분을 대체. 나머지 결정은 유지.

## 배경

사용자가 공유한 팀 대화에서는 응모권 발급 단계에서 어뷰징 요청을 차단하고 관리자에게 차단 내역을 보여주며 실제 추첨에서 응모자를 제외하지 않기로 설명했다. 사용자가 이 정책의 요구사항·도메인·API 초안 반영을 요청했다. 기존 spec에는 관리자 참여 허용·추첨 제외, 제외 반환과 전원 제외 종료가 남아 있어 정리가 필요했다.

## 결정과 이유

- 변경 전: 관리자 검토에서 참여 허용·추첨 제외를 결정하고 추첨 후보 필터·제외 사유 안내·응모권 반환·전원 제외 종료에 반영했다.
- 변경 후: 응모권 지급 전 서버 검증으로 차단된 요청에는 응모권을 지급하지 않고 사유·발생 시각·관련 요청·검증 근거를 보존하여 관리자에게 조회를 제공한다.
- 정상 접수된 유효 응모는 수량·차감 근거와 대조하여 추첨 후보로 확정한다. 차단 기록으로 사용자의 다른 정상 응모를 제외하지 않는다. 관리자 참여 허용·추첨 제외 결정과 그에 따른 제외 사유 안내·반환은 제공하지 않는다.
- 수량·가중치·중복 당첨·결과 정합성 검증과 응모자 없음 정상 종료는 유지한다. 신규 실행에서는 어뷰징으로 전원 제외되는 종료 흐름을 사용하지 않는다.
- 정책 원본은 [응모 규칙](../02-domain/entry.md), [추첨 규칙](../02-domain/drawing.md)과 [구현 범위](../00-requirements/scope.md)에 반영했다. 사용자가 이번 정책 변경의 검토 완료와 push를 요청해 ADR을 채택 상태로 변경한다. 차단 기준·적용 범위 등 후속 확인과 구체적인 구현·API 계약 검토는 아래 항목으로 구분한다.

## 검토한 대안

기존 관리자 제외 정책과 사용자가 전달·확인한 지급 전 차단 중심 정책을 대조했다. 별도 기술 대안 검증은 수행하지 않았다.

## 영향과 재검토 조건

- GD-84의 기존 병합 작업 이력은 보존하고 GD-130에서 추첨 제외 의존성 제거와 스냅샷 회귀 검증을 다룬다. 이 문서 변경으로 백엔드 구현이 완료됐다고 표현하지 않는다.
- 어뷰징 설계·core·storage·API 작업은 차단 기록과 관리자 조회 중심으로 정리한다. 검증 담당과 실제 지급 담당의 공동 경계 계약은 구현 전 확인한다.
- 지급 차단 적용 대상, 명확한 위반/의심의 판정 기준, 지급 후 점수 무효화·당첨 취소·재추첨 유지 여부, 마감 후 5분 일정 유지 여부는 [후속 확인](../00-requirements/pending-decisions.md#지급-전-차단-전환의-후속-확인)이다. 새 차단 기준을 임의로 도입하지 않으며 사후 처리와 일정은 후속 결정 전까지 기존 정책을 유지한다.
- 기존 데이터·Flyway·과거 판단·추첨 스냅샷·상태를 삭제하거나 소급 변경하지 않는다. 과거 제외 상태 조회 호환성과 공개 계약 전환은 구현 전 검토한다. 후보 스냅샷 저장소는 추첨 근거 보존에 필요하므로 제외 저장소와 구분한다.
- `02-domain/notification.md`, `05-api/notification.md`와 알림 담당 티켓은 사용자의 명시적인 범위 제외에 따라 수정하지 않는다. 신규 제외 알림 발생과 기존 `ENTRY_EXCLUDED`·과거 알림 호환성은 해당 담당자의 후속 검토가 필요하다.

## 2026-10-12 후속 결정 연결

당첨 취소·재추첨 유지 여부와 기존 사유 제한은 [ADR-019](019-admin-award-cancellation-and-partial-redraw.md)에서 관리자 사유에 따른 개별 취소·빈 자리 재추첨으로 확정했다. 위 본문은 당시 결정 이력으로 보존한다. 추첨 전 어뷰징 제외 폐지, 점수 처리·차단 기준·일정의 나머지 후속 확인은 유지한다.
