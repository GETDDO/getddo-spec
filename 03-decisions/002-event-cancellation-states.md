# ADR-002: 모든 상태에서 이벤트 취소 허용

- 상태: 채택
- 작성자 / 날짜: 사용자 지시에 따라 Codex 정리 / 2026-09-21
- 검토자: 사용자 명시적 결정, 별도 팀 검토 이력 없음
- 관련 작업 기록 / PR: 로컬 명세 수정, PR 미생성
- 대체한 ADR / 대체된 ADR: 해당 없음

## 배경

이벤트 취소가 가능한 상태는 미결정이었다. 사용자가 이벤트 취소는 언제든지 가능하도록 명시적으로 결정했다.

## 결정과 이유

- 변경 전: 취소 가능한 상태를 미결정 사항으로 관리했다.
- 변경 후: 관리자는 이벤트 상태와 관계없이 언제든지 취소할 수 있다. 추첨 완료·결과 발표 완료 및 종료 상태도 포함한다.

사용자의 확정 요구사항을 반영한다. 기준 정책은 [이벤트 도메인 규칙](../02-domain/event.md)을 따른다.

## 검토한 대안

별도 대안 검토 없음. 사용자 지시를 근거로 반영한다.

## 영향과 재검토 조건

- 백엔드: 이벤트 상태를 이유로 관리자 취소를 제한하지 않는다. 기존 취소 후 재개 불가 및 후속 응모권 반환 규칙을 적용한다.
- 프론트엔드·백오피스: 이벤트 상태만으로 관리자 취소 기능을 제한하지 않는다.
- 사용자 화면: 추첨·발표 이후에도 이벤트가 취소 상태로 변경될 수 있음을 반영한다.
- 이 결정은 취소 가능한 상태를 확정한다. 중단·재개 및 반환 관련 미결정 사항은 기존 문서에서 계속 관리한다.
