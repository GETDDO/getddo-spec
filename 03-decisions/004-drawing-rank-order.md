# ADR-004: 상위 등수부터 당첨자 선정 및 경품 배정

- 상태: 채택
- 작성자 / 날짜: 사용자 지시에 따라 Codex 정리 / 2026-09-21
- 검토자: 사용자 명시적 결정, 별도 팀 검토 이력 없음
- 관련 작업 기록 / PR: 로컬 명세 수정, PR 미생성
- 대체한 ADR / 대체된 ADR: ADR-001의 실제 선정 순서·후보 부족 시 배정 우선순위 미결정 부분을 확정한다. 나머지 결정은 유지한다.

## 배경

실제 당첨자 선정 순서와 후보 부족 시 경품 배정 우선순위는 미결정이었다. 사용자가 1등 → 2등 → 3등 순서로 결정됐음을 알렸다.

## 결정과 이유

- 변경 전: 실제 선정·경품 배정 순서와 후보 부족 시 배정 우선순위는 미정이었다.
- 변경 후: 1등 → 2등 → 3등 순서로 당첨자를 선정하고 경품을 배정한다. 이미 당첨된 사용자는 다음 등수 추첨에서 제외한다. 후보가 부족하면 상위 등수부터 배정하고 남은 자리는 미선정으로 처리한다.

사용자의 확정 요구사항을 반영한다. 기준 정책은 [추첨 도메인 규칙](../02-domain/drawing.md)을 따른다.

## 검토한 대안

별도 대안 검토 없음. 사용자 지시를 근거로 반영한다.

## 영향과 재검토 조건

- 백엔드: 실제 추첨 및 경품 배정에 상위 등수 우선 순서를 적용한다. 재추첨에서도 기존 당첨자와 경품을 유지하고 빈자리만 보충한다.
- 프론트엔드: 기존 3등 → 2등 → 1등 화면 표시 순서는 유지한다. 실제 선정 순서와 화면 표시 순서를 구분한다.
- 백오피스·사용자 화면: 후보가 부족하면 상위 등수부터 배정된 결과와 남은 미선정 자리를 반영한다.
- [ADR-001](001-drawing-consistency.md)의 실행별 정합성·결과 보존 원칙은 유지한다.
