# ADR-012: 이벤트·경품 동시 등록과 이벤트 수정 제한

- 상태: 채택
- 작성자 / 날짜: 사용자 정책 결정에 따라 Codex 정리 / 2026-09-23
- 검토자: 사용자 직접 결정 반영, 별도 팀 검토 이력 없음
- 관련 작업 기록 / PR: [작업 기록](../04-worklogs/2026-09-23-event-registration-and-editing.md), PR 미생성
- 대체한 ADR: [ADR-011](011-event-notification-changes-and-deletion.md)의 시작 시각 앞당김 관련 정책을 대체하고, 이벤트 삭제 시 알림 전체 제거 정책을 철회한다.

## 배경

사용자가 이벤트 CRUD 검토 항목에 대해 이벤트와 경품의 동시 등록, 등수별 한 종류의 경품, 중단·취소 상태 수정 금지, 일정 앞당김 금지를 정했다. 월말 소진용 이벤트 지정 조건은 이번에 다루지 않는다. 이벤트 삭제 알림에 대한 '변경 없음'은 직전 추가한 알림 전체 삭제 정책이 아닌 그 이전 정책 유지라는 사용자 정정에 따라 반영한다.

## 결정과 이유

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 이벤트·경품 등록 | 등록 흐름과 함께 완료할 범위 미명시 | 이벤트 등록과 동시에 경품·당첨 인원을 등록하고 함께 성공·실패 |
| 등수별 경품 | 같은 등수의 복수 종류 허용 여부 미명시 | 동일 이벤트의 등수마다 한 종류의 경품만 등록, 당첨 인원은 별도 설정 |
| 중단·취소 상태의 정보 수정 | 시작 전 수정 허용과 상태별 제한의 경계 불명확 | 중단·취소 상태는 시작 전이라도 정보 수정 불가 |
| 시작 시각 앞당김 | 앞당김에 따른 추가 알림을 생성하지 않음 | 현재 설정된 응모 시작 시각보다 앞당기는 변경 자체를 금지 |
| 월말 소진용 이벤트 지정 조건 | 추가 확인 대상으로 제시 | 이번 변경에서 추가 조건을 정하지 않음 |
| 이벤트 삭제 시 알림 | ADR-011에서 발송된 알림까지 전체 삭제하도록 추가 | 사용자 정정에 따라 추가 규칙 철회. ADR-011 이전 정책 유지 |

이번 사용자 답변을 근거로 반영했다. 기준 정책은 [기능 요구사항](../00-requirements/functional-requirements.md#이벤트-등록-및-관리), [이벤트 규칙](../02-domain/event.md#수정-및-삭제-제한), [알림 규칙](../02-domain/notification.md#일정-변경취소-알림)에 둔다.

## 검토한 대안

이전에는 일정 앞당김을 허용하면서 추가 알림을 보내지 않는 정책을 기록했으나, 사용자가 앞당김 자체를 금지하도록 변경했다. 이벤트 삭제 시 알림 전체 삭제를 유지한다는 해석은 사용자가 정정하여 철회했다. 나머지 항목의 별도 대안 검토와 선택 이유는 전달되지 않았다.

## 영향과 재검토 조건

- 백엔드: 이벤트·경품 등록을 함께 확정하고, 이벤트별 같은 등수의 경품 종류 중복과 중단·취소 상태의 수정 및 시작 시각 앞당김을 거절한다.
- 프론트엔드·백오피스: 이벤트 등록 시 경품 구성을 함께 제출하고, 등수별 한 종류의 경품과 별도 당첨 인원을 입력한다. 수정 가능 상태와 시작 시각 제한을 화면에 반영한다.
- 알림: 허용된 일정 변경과 취소에 기존 예약 갱신·안내를 적용하며, 앞당김 요청은 알림·예약에 반영하지 않는다.
- 이번 결정은 등수 개수의 상한, 이벤트 삭제 가능 조건, 월말 소진용 이벤트의 새 지정 조건을 추가하지 않는다. 중단 후 재개와 취소의 기존 상태 전환 규칙도 유지한다.
- 이벤트 삭제 시 연결 배너를 함께 삭제하는 기존 정책은 유지한다. 연결 알림 전체 삭제 규칙은 현행 명세에서 제거하며, 알림을 반드시 보존한다는 반대 정책도 새로 추가하지 않는다.
