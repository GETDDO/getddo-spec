# 공용 컨벤션

프론트엔드와 백엔드가 함께 사용하는 Git 및 협업 규칙을 관리합니다.

## 관리 범위

- 브랜치 역할과 이름 규칙
- Jira 이슈부터 병합까지의 개발 흐름
- Jira 에픽·태스크 작성 양식
- 커밋 메시지 규칙
- Pull Request 작성 및 리뷰 규칙

## 예정 문서

| 문서 | 내용 |
| --- | --- |
| branch.md | 브랜치 역할과 이름 규칙 |
| workflow.md | 공통 개발 흐름 |
| commit.md | 커밋 메시지 규칙 |
| pull-request.md | Pull Request 작성 및 리뷰 규칙 |
| [jira-epic.md](../templates/jira-epic.md) | Jira 에픽 작성 양식 |
| [jira-task.md](../templates/jira-task.md) | Jira 태스크 작성 양식 |

언어와 프레임워크에 종속된 코드 스타일은 공용 컨벤션에 포함하지 않고 각 코드 저장소에서 관리합니다.
